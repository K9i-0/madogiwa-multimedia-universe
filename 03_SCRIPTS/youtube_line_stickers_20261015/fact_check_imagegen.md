# Imagegen説明の修正（2026-10-15）

初稿では「絵は画像生成ツール」「Codexは指示づくり・加工コード」と説明し、画面も「人／画像生成／Codex」を並列に置いていた。そのため、ユーザーが別の画像サービスへ移動する必要があるように聞こえた。Codexから画像生成と加工を続けて依頼できることを明示する。

## 確認した公式情報

- [OpenAI公式：Image generation](https://learn.chatgpt.com/docs/image-generation)：Codexから自然言語で画像の生成・編集を依頼できる。`$imagegen`でスキルを明示的に使うこともできる。内蔵の画像生成はOpenAIのモデルを利用し、Codexの一般利用枠に計上される。
- [OpenAI公式：Pricing](https://learn.chatgpt.com/docs/pricing#image-generation-usage-limits)：ChatGPTプランに含まれる利用枠での画像生成と、APIキーで利用するときのAPI料金を区別している。画像生成はFreeプランでは利用できず、含まれる利用枠の上限後にはクレジットを利用する。
- ローカルのimagegenスキルも、標準の内蔵ツール利用にはAPIキーが不要で、API経由の経路と区別している。

「ChatGPTの利用枠」を動画では「対応プランに含まれるCodexの利用枠」と表現する。ChatGPTの通常チャットの画像生成回数と同じカウンターだとは説明しない。無制限・すべてのプランで利用可能・常に追加料金なしとは述べない。

公式ページには現在の内蔵モデル名も記載されているが、第一弾で実際に用いたモデルのバージョンをこのページだけから特定できないため、動画では「OpenAIのモデル」に留める。

## 台詞の差し替え

- `flow-05`：はい。CodexのImagegenという画像生成機能で、OpenAIのモデルに絵を描いてもらいます。ChatGPTの対応プランなら、プランに含まれるCodexの利用枠で使えます。
- `flow-06`：絵を作るところから、同じチャットで頼めるんやな。
- `flow-07`：そうです。原画の生成から、画像の加工や書き出しまで続けて頼めます。人は、どんなスタンプにしたいかと、出来上がりが狙いどおりかを判断します。

役割図も、Codexの中に「Imagegenによる原画生成」と「コードによる加工・書き出し・検証」が含まれる構成へ変更する。
