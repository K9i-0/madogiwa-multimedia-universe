# BBQホラー：肉みつけた

前作に続くH3 480p Turbo制作。完成720p。初回生成をユーザーが依頼。

1. 普通の牛肉のBBQ。よーたん「あれ、肉足りなくない？」。そば屋「ちょっと待っててください」。そば屋がトングを置き、庭奥へ出ていく。
2. 薄暗い森で青く丸いゆめみんが浮く。静かな長めの間。
3. 白T・茶色腰エプロンのそば屋が現れ、無言で素手でゆめみんを捕獲。捕獲成立直後に切る。ゆめみんの体形は青い丸い前部・白い後部・点目・短い鼻、腕と脚なし。
4. 同じBBQ会場。よーたんとやめ太郎の2人だけ。スマホの通知音→やめ太郎がスマホを見る→「そば屋さんが肉みつけたって！」。そば屋は帰らず、ゆめみんも会場に出さない。よーたんが暗い出入口を見る。暗転。

ゆめみんを食べる・調理する・解体する・残骸を映す場面は一切なし。恐怖は捕獲と通知の暗示のみ。前作のちくわ・毒ちくわは登場しない。会話3行以外の発話・悲鳴・ナレーションなし。

4カットを同じA100で順次生成、各画像は内蔵imagegen。冒頭の控えめなCorncobは既存採用曲を再利用し、森で停止、最後は環境音のみ。H3埋め込み音声を基本とし不良発話は編集・ローカルIrodoriで修復。生成原本保持。白Tは前作のpositive_cloth文面を採用。
