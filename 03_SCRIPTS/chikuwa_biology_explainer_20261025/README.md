# ちくわの生態――海と山に暮らす、身近な古代動物

2026-10-25制作。完成版：`final_remotion_chikuwa_biology.mp4`、11分44.467秒、1280×720、30fps、21,134フレーム。ずんだもん・四国めたんの生物解説。ユーザー採用台本を119発話で動画化。

- セリフと画面指定：`dialogue.json`（`dialogue.txt`から初回転記）
- 字幕原文は維持。`readings.json`と共通VOICEVOX辞書から音声用の読みを準備。
- 採用音声：エピソード直下の`voice_*.wav`。`voices.json`から現在使用するファイルを特定。
- エンジン：VOICEVOX 0.25.1。四国めたんノーマル2／速度1.13、ずんだもんノーマル3／速度1.15。24kHz、前無音0.09秒、後無音0.12秒。
- 画面：720p/30fps、40区間。左右の坂本アヒル式立ち絵、波形RMSに基づく口差分、まばたき。分類表、生態模式図、既存写真と動画。ずんだもんも毒ちくわを外見で識別できない世界観を維持。
- 既存映像：25（港）、42（大ちくわ）、88（毒ちくわ事件）、2026-10-23秋ニュース。素材元は`assets.json`。既存の物理・演技はそのまま使用。
- タイミング正本：`remotion/src/edit-manifest.json`。最終尺は119音声の実測＋会話間＋資料クリップ。尺合わせの音声速度加工なし。
- 字幕はBudouXの文節で分割し、2行にバランス配置。長い発話内での字幕切替は文字数配分による概算。音素単位の強制アラインメントではない。
- 音：会話-18 LUFS、BGM-35 LUFS、原音クリップ-19 LUFSを出発点。資料再生中は会話なし・BGM減衰。締めは導入曲の再提示をさらに2.5dB下げ、会話後も持ち上げない。
- フィクション設定：管状動物門・学名・解剖・生態の新設定は今回の採用案。実在の分類の説明ではない。実在の動物学資料と、過去作で確定した設定を混同しない。

## 再現

リポジトリルートから実行。ローカルに既存の入力動画・BGM・立ち絵が必要。

```sh
npm ci --prefix 03_SCRIPTS/chikuwa_biology_explainer_20261025/remotion
.local/voicevox-explainer/venv/bin/python 03_SCRIPTS/chikuwa_biology_explainer_20261025/remotion/render.py
```

音声を変更する場合のみ先に`prepare_voice.py`。クエリとエンジン版・話者からキャッシュを識別する。音声を再利用する通常レンダーでVOICEVOXへの接続は不要。

## 検証

詳細は`audit.json`。全40場面と4クリップのプレビューを目視。画面上端の見出し切れ、字幕改行、港の資料映像の時間原点を修正。AudioQueryのモーラ検査で開口部・准教授・有毒の種・間・付けての誤読を修正。一般化可能な2語を共通辞書へ追加し、辞書回帰テスト12件成功。

`reading_audit.json`、`speech_asr_audit.json`は機械検証。聴覚による通し試聴、発音・抑揚の自然さ、リアルタイムの口パクの最終判断は未実施。静止画と機械検証を聴感合格と扱わない。

原音資料に表示済みのニュース字幕は保持。メンバーの新規字幕・新規音声は追加していない。概要欄用クレジットは`youtube_description.txt`。投稿・公開は行わない。
