# Codexで動くLINEスタンプを作る — 実例と掛け合い版 v7

2026-10-16。承認済みv6をベースに、第二弾の販売準備・審査中の表現と、公式情報に基づくUltraの並列分担の説明だけを調整。

第一弾・第二弾の制作知見を紹介。第一弾の販売申請担当はそば屋さん。第二弾は動画制作時点で審査中。販売に向けて準備中として紹介する。第二弾の候補を第一弾の制作資料として説明しない。

冒頭タイトルは「窓際族LINEスタンプ第一弾」。通知→よーたんからのLINE→Outlookの辞令→「Pythonエンジニアみたいに言うな！」までで茶番を終える。画面全体の短い白フェードで自己紹介へ切り替える。本編では第二弾全8個を提示する。

やめ太郎は普段のIrodori、たこさんはVOICEVOX中国うさぎ。「よーたんからや！」は通知に自然に気づいた日常の声にし、大げさな喜びや叫びにしない。通知の一言は候補を比較して選ぶ。窓際への転用には謎に誇らしげに、脱衣のツッコミはぼそっと呆れる。字幕表記と音声用の読み・演技指定を分ける。「案出し」の読みは「あんだし」。

案出しは8個を1枚にまとめ、全体を比較しやすくするとともに、Imagegenの呼び出し回数を減らす。人が付きっきりで選ぶ段階は速度、任せて待てる仕上げは品質を重視する。

Codexの設定は投稿者個人の使い分けとして紹介する。モデルはGPT 6 Astra。案出しではeffort Light、仕上げではeffort Ultraを選んでいるが、好みや待てる時間で変えてよい。Ultraは複数エージェントによる並列分担を活用するモードとして短く説明する。公式根拠は `fact_check_effort_ultra.md`。Codex側の設定であり、Imagegenの画質設定の切り替えではない。設定による結果の保証や、唯一の推奨として説明しない。

ChatGPTのプランの選び方は、コンテンツ制作を目的とした別動画で取り上げたいテーマとして短く触れる。この動画でプランや価格の比較は始めない。

透過の失敗は当時のスクショとGitの実際の不良APNGを使用。同じフレームの背景を白→黒に替え、消し残しを発見し、修正後を見せる。意図的に追加した細い白フチは不良扱いしない。出典は `first_set_alpha_history.json`。

画面のプロンプト例は `remotion/tip-prompts.json`。音読せず読む間を設ける。画像処理ソフトの呼び方は「ツール」に統一する。締めは、たこさんの「やっぱやめさんも窓際族ですね」で会話を止める。以下のセリフは `remotion/dialogue.json` と一致する。
