# 窓際族物語を初心者向けに紹介する — 初稿 v1

ずんだもん＆四国めたん。2026-10-19のチャット台本と導入・プロンプト紹介のFBを反映。
完成初稿：1280×720 / 30fps / 20797フレーム（693.233秒）。
音声：VOICEVOX 0.25.1、ずんだもん・ノーマル3（速度1.15）、四国めたん・ノーマル2（速度1.13）。
冒頭6秒は映像のみ。出社インポッシブルを0–5秒、12–16秒、21–26秒の順で無音再生し、以降も原音・BGMなしで会話。
原音付き紹介は「替え玉出社」30秒。デバッグ祈願は完成動画がローカルにないため制作参照画像で紹介。
ゲームは実行画面・既存開発検証画面・カード試作デザインを使用。完成・公開済みと一括表現しない。
プロンプトを見せる画面は公式サイトの実ページを2026-10-19に取得。
制作体制・実在モデルの情報はユーザー提供。福ギュン／無職やめたろうは正本表記。
BGM：ほのぼのワルツ【リコーダー】／エクシエ。本編のみ、最後まで控えめな音量でフェード。
TheFatRat - Unityは今回未使用（プロジェクト宣伝用途のためテンプレ採用例を継承しない）。

## 音声読みの監査

- 「立ち飲み処」：タチノミショ→タチノミドコロ。共有辞書へ登録。
- 「各話」：カクハナシ→カクワ。共有辞書へ登録。
- 「動きや間」：演技の間なのでマ。該当行の全文speech_overrideで指定。字幕原文は維持。
- 全126発話のAudioQueryかなを点検。主観的な通し試聴は未実施。
