# 毒ちくわ v2 改訂

ユーザーFBを反映。初回入力・動画は保持。

- よーたん・福ギュンは通常シートの服装。よーたんのギターとストラップだけ除外。
- 手帳提示は福ギュン本人の顔と手帳を同一画面で示す単独ショット。相手は画面外。余計な警官・鑑識を削除。
- 入場から室内へハードカット。室内はよーたん左、福ギュン右。歩行・立ち位置移動をなくす。
- そば屋の初登場は「え、何で略した？」の後。背景にも先出ししない。
- 食卓へカット後はそば屋を中心に撮影。福ギュンの警告は画面外。転倒時も二人を無理に配置しない。
- 福ギュンの笑顔を抑え、全員真剣な演技。
- 「証拠品」はしょうこひんと明記。
- そば屋の最終台詞はユーザー指示で正典音声へ後付け。仮面は変形させず、未修正のWan発話は完成音声から除く。
- 30秒・480P、完成720p。v2設定はwan3_config_v2.json。
