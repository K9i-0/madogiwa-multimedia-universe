# YouTubeサムネイル見直し（2026-10-11）

対象は、このローカル環境で制作され、確認時のYouTube再生数が0〜9回だった公開中の動画39本。
Studioのエピソード単位ではなく、公開YouTube IDに紐づく制作版とローカル原本を照合した。
同じエピソードに別作者の制作版がある爆走タンクローリー篇は対象外（excluded.json）。

35本が1分未満、4本が1分以上。すべて完成動画内の実フレームを採用した。
人物が大きく見えること、その回特有の衣装・小道具・行動が伝わることを優先。
生成画像、顔の加工、追加文字、AI超解像は使っていない。
既存字幕・ロゴは動画内に存在するものをそのまま保持。
16:9の1280×720 JPEGへLanczosで一度だけリサイズ。異なる比率は歪ませず余白を付ける。

- `review.html`: 全採用サムネイルの一覧（クリックでYouTubeへ移動）。
- `selections.json`: YouTube ID、確認時再生数、原本パス、抽出秒、採用理由。
- `thumbnails/`: 採用画像。
- `extract.py`: 原本から同じフレームを再抽出（リポジトリルートから実行）。
- `apply.py`: 旧サムネイルをローカル保存してYouTube thumbnails.setへ反映。成功済みIDはスキップ。
- `results.json`: API更新結果と採用画像のSHA-256。
- `verification.json`: 公開CDN上の画像との照合結果。
- `out/`: コンタクトシート、更新前画像、公開確認画像（Git管理外）。

名探偵ヨータンは36.2秒、紫の毒ちくわを口に入れた瞬間を採用。
動画本体、タイトル、説明、公開範囲は変更しない。
