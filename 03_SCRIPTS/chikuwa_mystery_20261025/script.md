# めたんのミステリー研究所 第2回：ちくわ人工物説

採用方針v12：ずんだもんは「ちくわは生き物」という世界の常識を最後まで守る。めたんと研究員が、観察・実験から人工ちくわ流通説を唱え、さらに陰謀論へ飛躍する。人工ちくわと政府・企業による隠蔽は作品内で実在。研究員は中口・霜重のみ。北原の調査を中口へ統合。林・江本は登場させない。分類・生態・研究内容・T社は作品内の架空設定。


## intro / opening

**めたん**：海に生息し、山にも分布する、身近な生き物。ちくわ。

**ずんだもん**：秋は山のちくわがおいしいのだ。

**めたん**：しかし今、そのちくわに、作りものが紛れ込んでいるという疑惑が持ち上がっているわ。


## intro / claim

**めたん**：魚の肉をすり潰し、棒に巻いて焼く。それを、本物のちくわとして売っているというの。

**ずんだもん**：なんでそんなことするのだ。ちくわを採ればいいのだ。


## intro / title

**めたん**：私たちが食べているのは、生き物なのか。それとも、作りものなのか。今日は、この謎に迫るわ。

**めたん**：めたんのミステリー研究所へ、ようこそ。このチャンネルでは、身近な常識に潜む謎を、研究員たちの調査とともに追っていきます。


## biology / species

**めたん**：海産のウミチクワと、山産のヤマチクワは、共通祖先から分かれた別の種。管状動物門に属し、中央の穴で水や空気を通す動物よ。

**ずんだもん**：このあたりは義務教育でみんな習うのだ。ちくわが生き物なんて、いまさら説明することでもないのだ。


## biology / escape

**めたん**：過去の記録映像でも、野生個体の移動が確認できるわ。

【過去作クリップ：escape】

## biology / comparison

**めたん**：こちらは食用種と有毒種。外見だけでの判別は困難とされているわ。

**ずんだもん**：全く見分けがつかないのだ。


## biology / attraction

**めたん**：有毒種にはビール臭があり、代表的な天敵、ソバヤを引き寄せてしまうの。


## experiment / nakaguchi

**めたん**：では、店で買ったちくわにも、生き物の特徴は残っているのか。調査したのが、広域未確認生物研究所の中口研究員よ。


## experiment / meal

**めたん**：中口研究員は、食感の比較にも熱心でね。昨日は、調査に使った市販品と天然個体を、磯辺揚げにして食べたそうよ。

**めたん**：では、彼が残した調査記録を見ていきましょう。


## experiment / analysis

**めたん**：購入品から、魚肉に似たタンパク質と、加熱で固まった組織を確認。均一な穴や、巻いたような継ぎ目も見つかったの。

**ずんだもん**：焼いたちくわを調べて、焼けていると言われても困るのだ。


## experiment / process

**めたん**：そこで魚のすり身に塩を加えて練り、棒に巻いて加熱。ちくわに似た、弾力のある筒状の食品を再現したわ。

**めたん**：味、弾力、焼き色まで再現できたわ。残る相違点は、生命活動だけだった。

**ずんだもん**：一番大事なところが残っているのだ。

**めたん**：もちろん、焼いた天然物も動かない。だから、動かないというだけでは区別できないの。でも、魚から見分けにくいものを作れることは分かったわ。


## supply / poison_absence

**めたん**：調査記録で、特に注目したいのは毒ちくわ。野外では食用種に混じるのに、調べた市販品には、一切含まれていなかったの。

**ずんだもん**：お店に出す前に、ちゃんと選別しているのでは？


## supply / selection

**めたん**：外見では判別できず、ビール臭も洗浄や加熱で失われる。成分検査なら分かるけれど、一本ずつ組織を採って調べる必要があるわ。

**めたん**：ところが、市販品を全数検査しているという記録もない。どうやって、毒ちくわだけを取り除いているのか。

**めたん**：市販品から毒が検出されないたびに、中口研究員は疑いを深めていったわ。

**ずんだもん**：検査に合格して、容疑が深まったのだ。


## supply / official

**めたん**：企業の説明は、食用種だけを育てる閉鎖型の養殖。政府も、養殖技術の発展によって、季節を問わず安全に出荷できるとしているわ。

**ずんだもん**：そうなのだ。毒ちくわが入ってこない場所で育てればいいのだ。学校でも習ったのだ。


## supply / secret

**めたん**：中口研究員は、養殖施設と繁殖工程の資料を求めたの。回答は、独自技術のため非公開。代わりに提供されたのは、工場の加工映像だったわ。


## supply / growth

**めたん**：魚肉を練り、棒に巻き、加熱する。卵も幼体も出てこない。これは、中口研究員が試した製法と同じなの。

**めたん**：魚肉から作るなら、季節を待つ必要も、有毒種を選り分ける必要もない。


## supply / poison_logic

**めたん**：毒ちくわを、一匹残らず取り除いているのではない。最初から、生きたちくわを一匹も使っていないのではないか。

**ずんだもん**：加工の前に、ちゃんと養殖しているのかもしれないのだ。まだ決めつけられないのだ。


## evidence / handoff_market

**めたん**：中口研究員は、この疑いを確かめるため、市販品と天然個体を第三者機関の比較鑑定に出す予定だったの。


## evidence / missing

**めたん**：ところが、発送の直前、証拠品がすべて消えていたの。市販品も、天然個体も。比較に必要なものだけが、きれいになくなっていたわ。

**めたん**：何者かによって、証拠品が盗まれた可能性が高い。人工ちくわの流通を知られたくない組織が、研究所にまで手を伸ばしたのよ。


## evidence / isobe

**ずんだもん**：それ、さっき磯辺揚げにして食べたって言ってたのだ。

**めたん**：……本人は、食感を比較するためだったと説明しているわ。

**ずんだもん**：送る分まで食べたのだ？


## evidence / verdict

**めたん**：ええ。鑑定用の現物は、一つも残っていなかった。測定記録はあるけれど、今回の試料を第三者に検証してもらうことはできなくなったわ。

**めたん**：ただ、研究員は最後まで比較を続けたそうよ。市販品も、天然物も、揚げたてがおいしかったと。

**ずんだもん**：研究の成果が夕飯の感想なのだ。
