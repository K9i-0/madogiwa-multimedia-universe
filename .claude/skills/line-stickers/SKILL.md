# LINEスタンプ制作

MMUのスタンプを、採用原画と再現可能な加工処理から仕上げる。制作物パスはリポジトリルート基準。ユーザーの今回の指示を優先し、過去の演技・枚数・3秒という設定を全作品の必須条件にしない。

## 最初に制作記録を確認する

1. `27_LINE_STICKERS/README.md` と対象セットの `README.md`・`set.json` を読み、静止版／動く版、採用内容、依頼範囲を特定する。
2. アニメーションの新規制作、作り直し、「第一弾のように」という依頼では、実装前に [制作方式と履歴](references/history.md) を読む。対象セットの**採用原画・実際の組立コード・再生順**も確認する。READMEの説明だけから方式を推測しない。
3. 最新の採用原画を画像として見る。新規描画・人物の描き直しでは正典も確認し、絵柄と人物同一性の参照を分ける。そば屋では `02_CHARACTERS/01_Sobaya.md` と現在の `03_SCRIPTS/00_TEMPLATES/characters/character_sobaya_basic_sheet.png` を併用する。規格変換や単純なcropだけなら、出典と対象画像の確認で足りる。

原画が見つからないときは `rg --files 27_LINE_STICKERS`、セットの台帳、Git履歴から探す。「記録がない」と即断して別方式を作らない。承認済みの構図や動作は今回の修正対象だけを変える。

## 依頼に応じた制作

- **企画・静止画**：用途とセリフ、絵のオチ、ポーズの重複を整理する。候補数はユーザーの依頼に合わせる。新規イラスト・描き直しはCodexの `imagegen` を使い（Claude Code等のCodex以外では`codex-imagegen`スキル経由で実行する）、正典の顔・身体構造を維持する。候補、採用、今後用の退避を区別する。
- **動く版**：[連続原画・透過・演技](references/animation-and-alpha.md) を読む。標準は連続した姿勢を1枚のシートに生成し、採用コマを切り出して組み立てる方法。身体の局所ワープや顔だけの拡大で足りない姿勢を代用しない。
- **透過・文字・背景の修正**：同じ参照の該当節を読み、現行の採用原画・マスク・文字レイヤーを直す。きれいなRGBAを白背景除去からやり直さない。修正後は納品ファイルから白黒プレビューを再生成する。
- **main/tab・完成・申請用書き出し**：[規格と納品](references/delivery.md) を読み、必要に応じてLINE公式の現行規格を再確認する。動く版mainはAPNG、tabは静止PNGという違いを忘れない。

ユーザーの動作説明が雰囲気の共有なら、関節の座標指定として固定せず、絵に合う自然な芝居と間へ翻訳する。動きを先に相談したいという依頼には設計を示すが、既に任された制作や承認済み内容に再承認を挟まない。

## このプロジェクトでの完成条件

- 全コマで顔・手・身体の接続、小道具、静止背景、文字の穴と輪郭を目視する。形式検査の合格を絵や演技の合格と同一視しない。
- 動く版は最終APNGをデコードし、経過時間を合わせた白・黒背景の一覧GIFを作る。実寸の可読性と最後の姿勢を読める間を確認する。
- セット全体の完成・申請用画像が範囲なら、本体に加えてmain/tabと画像だけのZIPを用意する。個別修正では既存の一覧・ZIPも更新する。main/tabだけの依頼で採用済み本体の演技を作り直さない。
- 採用原画、実際のプロンプト、採用順・保持時間、切り出し・固定範囲、検証結果をセット内に記録する。新しい知見は該当参照へ追記する。既存セットを新セットの作業場所として上書きしない。
- 画像一式の完成とLINEへの申請・公開は区別する。画像作成だけの依頼では外部申請を行わない。申請操作も指示されている場合は、その既存の指示の範囲で進める。

## 既存コードの使い分け

第2弾は `27_LINE_STICKERS/sets/02/tools/` の `build.py` → `build-listing.py` → `verify.py` → `review-package.py`。コマ選択・マスク座標はこのセット専用で、汎用テンプレートではない。新セットでは仕組みを再利用し、原画・座標・タイミング・顔の検査範囲を構図に合わせる。

第一弾の方法は [history.md](references/history.md) の証拠パスへ戻る。「Codex Petsのように」はこの文脈では連続原画方式を指す。Petsの登録・有効化や、一般動画向けのWan生成・720p化をLINEのAPNGへ持ち込まない。
