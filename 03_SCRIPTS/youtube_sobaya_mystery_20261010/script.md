# めたんのミステリー研究所：SOBAYA（改稿 v6）

各パートを「知られたオカルト話 → 雑な共通点 → 大発見扱い」で整理。霜重がアニメ映画の視聴を研究実績と誤認するネタは一度だけ。宇宙パートは容器のちゃぷちゃぷ音を通信と解釈する。ずんだもんは通常は聞き役、辛辣さは節目へ限定。

## 架空の研究者・記者

- 木村（キムラ）：広域未確認生物研究所／形態比較
- 林（ハヤシ）：中央映像解析センター／映像解析
- 霜重（シモジュウ）：狭間文明研究所／旧文明研究
- 中口（ナカグチ）：比較言語文化研究会／儀式・言語調査
- 北原（キタハラ）：未知環境生理研究所／宇宙での行動・生理
- 江本（エモト）：未確認ニュースネット／記者
