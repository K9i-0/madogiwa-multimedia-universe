# Codexで動くLINEスタンプを作る — 実践のコツ版 v3

2026-10-15。ユーザー採用の再構成稿を動画化。「動画にして」の指示に基づく。

## 今回の構成

最初に8個を一覧で出す、違和感があれば複数案から選ぶ、構図が決まったらきれいに描き直す、Pets用スキルの連続原画手法を応用する、動きの雰囲気を伝えて比較する、白黒両背景で確認する、描き直す変更と通常画像処理を使い分ける。視聴者が使える頼み方と判断を中心にする。

## 維持する導入

v2のintro-01〜intro-13とmain-01〜main-03を、採用音声・台詞・間・字幕時刻・演出ごと維持する。比較正本は `intro_reference_v2.json`。Outlookの辞令、廃村（ハイソン）／Pythonエンジニアの掛け合い、「実例いらんねん！」後の間・タイトル、挨拶も維持。削除済みの「栄転だそうです」「廃村に栄転することある!?」を復活させない。

## 素材と表現

- 第一弾の販売中スタンプが主題。案出し・構図選び・再描画・先輩の演技は、第二弾での実例だと分かる表示にする。
- 8個入り画像はA/B/Cを大きく見せ、差を見比べる。全てを小さく同時表示し続けない。
- 「働いてるか？」の立ち姿／パーティション／椅子を比較。Bが採用され、Cの椅子案は「二流」に転用された。
- 腕固定の動き3候補は全て不採用。そこから採用したように見せず、雰囲気を伝え直した経過として紹介する。
- 原画・文字の修正前は実在する入力を使用。完成品に汚れを加えて過去の失敗を捏造しない。rawの白背景付き原画と、透過処理後は明示して区別。
- Petsの出典は `fact_check_pets.md`。OpenAI公式のLINEスタンプ制作法とは言わない。Imagegenと利用枠の根拠は `fact_check_imagegen.md`。
- 指示例は画面カードとして提示。全文を勝手に読み上げる台詞は追加せず、読むための間を確保する。正本は `remotion/tip-prompts.json`。

## 制作仕様

1280×720・30fps。既存の白緑Excel風テンプレ、やめ太郎左・たこさん右。台詞と音声用の読みは `remotion/dialogue.json`、実測の字幕・口パク時刻は `remotion/src/edit-manifest.json`。約10分を想定し、音声の実測で最終尺を決める。

やめ太郎は正典参照Irodori-TTS v4.1-Small、たこさんはVOICEVOX中国うさぎ61・速度1.1・音高0。前回の音声FBを引き継ぎ、追加の声・長い語尾を検査する。ASRだけで自然さを合格としない。BGMは既存2曲を静かな音量で継続、最後に音量を持ち上げない。クレジットは概要欄。
