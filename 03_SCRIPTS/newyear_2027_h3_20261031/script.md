# 2027 新年挨拶 — H3試作 v1

ユーザー依頼：羊姿のゆめみん・たこさん・やめ太郎、袴で撮影する福ギュン。そば屋だけバフォメット。去年のケンタウロスと、余った馬の首＋そば屋の下半身でオチ。

## 台本
1. やめ太郎「あけましておめでとうございまーす！」→ゆめみん「ゆめぇ〜〜」（羊のように震える鳴き声）→福ギュン「みんな可愛いギュン！」
2. そば屋「あの……僕の衣装だけ、なんか変じゃないですか？」→やめ太郎「去年もそんな感じやったやん。」→そば屋「去年はまだ馬だったじゃないですか。」
3. 回想：ケンタウロスそば屋の乾杯姿から右へカメラ移動。馬の頭と首＋黒ジーンズの人間の下半身の余り。いななき。新年挨拶テロップで締め。

## 入力・設定
- built-in imagegenで3枚の場面参照を生成。正典シートと福ギュン正典写真を使用。元のユーザー添付2026年画像は会話で確認できるが一時ファイルは既に存在しなかったため、構図の記憶とそば屋正典から描き直した。
- H3 R2V、480p Turbo、864×480、24fps、8step、A100 1worker。260/362/175 frames、合計33.2083秒。
- 正典WAVを声質参照として使用し、今回の台詞はH3が生成。新規Irodori TTS生成なし。ゆめみんの羊風鳴き声と馬のいななきもH3生成。
- 開始CU 98.94、開始時稼働0。追加購入なし。配置地域unknown（取得できた場合はログ参照）。
- 動画原本・ジョブ中間物はgenerated/へ保存、Git除外。
- 初版は出来次第提示。生成後の顔・仮面・羊の鳴き声・台詞の実現度は別途確認する。

## 試作結果
- 全3場面を生成・回収しSHA256照合。Colab停止済み（稼働0、消費率0）。観測残高98.94→96.81 CU（差2.13 CU、表示遅延あり）。
- GPU側処理871.39秒。推論・検査は152.21 / 211.28 / 75.88秒。
- ch01は125フレーム、ch02は209フレームで予定台詞後の余分な発話らしい部分を除去。ch03は175フレーム保持。通し版509フレーム／24fps＝約21.21秒。ASR時刻に基づく暫定編集で、聴感の合格判定ではない。
- 480p原本は全尺保持。720pへ一度だけLanczos拡大し、微小余白を付けて16:9へ。Remotionで「去年のお正月」「今年もよろしくお願いします」を追加。
- 代表フレームで人物識別と衣装、ケンタウロスと余りの造形を確認。仮面の口変形・やめ太郎の顔細部の変化、回想冒頭から余りが端に見える点が残る。追加生成なし。
- 再現：assemble_v1.py / remotion/src/edit-manifest.json / prompt_ch01〜03_v1.txt。

- v1提示後、終端の挨拶がそば屋の顔へ重なるためv2で下へ移動。映像・音声は同一、v1保持。
