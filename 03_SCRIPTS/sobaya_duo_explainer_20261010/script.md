# そば屋って、どんな人？

たこさんが解説、やめ太郎が体験者としてツッコミを入れる。各8種の表情とポーズを全て使用し、顔の位置を保った口パクを合わせる。左右はたこさん左（反転）／やめ太郎右。背景は無地に近い生成り、中央にそば屋の正典シートと原作漫画。前回から引き続き声と動作を確認しやすいBGMなし。

## 内容・出典

- 人物紹介、41歳／180cm／100kg、見た目と優しさ、怪力：02_CHARACTERS/01_Sobaya.md。
- 段ボール椅子：原作第1話。
- ベランダ席、ビールが冷えたまま：第3話。
- 立ち飲み処：第4話。
- 落下・人的被害なし・片付け：第6話。
- 再建とやめ太郎の手伝い：第8話。
- ビール永久無料キャンペーン：第5話を回想として紹介。
- 捕縛と壁を破った脱走：第11〜12話。
- 画像は既存原作から引用。新規の人物紹介は2026-10-05更新のそば屋標準シート。白仮面とグレー肌を保持。過去原作画像は改変しない。

## 台本・音声

台本の正本はdialogue.json。表示文と音声用読み（reading）が異なる場合は分けて保持。

Irodori-TTS v4.1-Small、正典Takosan_voice.wav seed43／Yametaro_voice.wav seed7。caption空、本文CFG5、uncut1。やめ太郎の初期尺倍率0.70、要修復行のみ0.85。たこさん1。モデル・参照・seed・倍率は各行へ記録。生成後の速度変更・語句カットは行わず、編集用WAVのみ-18 LUFS／48kHzへ調整。

## 再現

1. リポジトリルートから本ディレクトリのgenerate_voice.py、repair_voice.py（読み修復）、finalize_voice.py（採用文への改稿）を実行。
2. remotion/prepare_assets.pyで共有素材・正典画像を準備。
3. Irodori環境のPythonでremotion/prepare.pyを実行し、実測尺とRMSを作る。
4. remotionでnpm ci、npm run typecheck、npm run render。
5. node export_sprites.mjsで同じ合成処理による32枚の透過差分を再書き出し。

Remotionと関連パッケージは4.0.534固定（npm view確認）。1280×720・30fps。タイミング正本はremotion/src/edit-manifest.json。

## 検証の扱い

ASRは台詞の自動照合であり、実際の試聴による声質や演技の承認ではない。認識揺れがある箇所を再生成し、結果をasr_screening.jsonに保持。視聴での判断用に完成動画と差分一覧を提供する。
