# Codexで動くLINEスタンプを作る — 実例と掛け合い版 v5

2026-10-16。Irodori版v3をベースに、ユーザーのFBと採用されたツッコミを反映。台本修正と動画化の依頼に基づく。

第一弾・第二弾の制作知見を紹介。第一弾の販売申請担当はそば屋さん。第二弾の候補を第一弾の制作資料として説明しない。

冒頭タイトルは「窓際族LINEスタンプ第一弾」。通知→よーたんからのLINE→Outlookの辞令→「Pythonエンジニアみたいに言うな！」までで茶番を終え、短いタイトル転換後に自己紹介。本編では第二弾全8個を提示する。

やめ太郎は普段のIrodori、たこさんはVOICEVOX中国うさぎ。よーたんの通知には妙にうれしそうに、窓際への転用には謎に誇らしげに、脱衣のツッコミはぼそっと呆れる。字幕表記と音声用の読み・演技指定を分ける。

透過の失敗は当時のスクショとGitの実際の不良APNGを使用。同じフレームの背景を白→黒に替え、消し残しを発見し、修正後を見せる。意図的に追加した細い白フチは不良扱いしない。出典は `first_set_alpha_history.json`。

画面のプロンプト例は `remotion/tip-prompts.json`。音読せず読む間を設ける。以下のセリフは `remotion/dialogue.json` と一致する。
