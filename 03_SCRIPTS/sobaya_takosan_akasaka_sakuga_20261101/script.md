# 赤坂作画回：そば屋 vs たこさん（Wan作画回テスト）

2026-11-01 ユーザー依頼「呪術廻戦の作画がすごい回みたいな映像をWanと編集で。プロンプトを頑張ってどこまでできるか試す。お題は赤坂の東京タワー周辺でそば屋とたこさんがバトル、ド派手なエフェクトと破壊描写」。

## 方針
- 作品名・スタジオ名はプロンプトに書かず、作画回の特徴（手描き2Dセル、太さの変わる線、2トーン影、作画の2コマ打ち、スメア、インパクトフレーム（白黒反転）、黒い稲妻＋赤い火花、パース強調、回り込みカメラ、手描きのエフェクト作画）を言語化して指定。
- 30秒・単一タスク・480P・16:9。音声はWan生成の効果音・環境音のみ（音楽・台詞なし、`audio_sync_strategy=no_visible_speech`）。BGMやインパクト強調は編集で後付け予定。
- 夜の赤坂の街から東京タワー（芝公園）へ戦場が移る構成。
