# プロフェッショナルの朝は、遅い。 — Shorts編集

Studio v2の登録済み完成原本（15秒・450フレーム・30fps）を使用。横画面全体を保持し、720×1280の採用レイアウトへ配置した。音声は元完成版のAACを再圧縮せず保持する。

Studioのプロンプトは5秒×3クリップの計画だが、実際の完成版は15秒の一続きの映像へ台詞が集約されている。字幕の順序と尺は実音声の無誘導ASRを照合し、計画上の時刻を流用しなかった。発話されていない「午前11時42分。たこさんが出社した。」は追加していない。話者名と色は共通正本を使う。

末尾13.1〜15秒の追加ナレーション句はプロンプトに存在せず、2回のASRでも末尾語が一致しなかったため、その句だけ字幕を付けず元音声を保持した。「開いて、閉じる。」までは字幕に含めた。推測した語を確定字幕にしない。

編集時刻の正本は `shorts-manifest.json`。技術監査は `technical-audit.json`、目視監査は `visual-audit.json`。全編デコード・元音声stream SHA一致と全字幕中間点・先頭末尾を検証する。静止画確認とASRを、人による通し試聴の実施とは区別する。
