# AIへの実行指示：ColabでMiniMax H3を使う

更新：2026-10-31。v1動画に添える制作手順。動画資料は [guide.md](guide.md)。未公開草稿。

ユーザーの題材・登場人物・参照画像・参照音声から、H3の480p Turbo動画を生成し、720pに編集して納品してください。計画の説明だけで終わらず、実行可能な工程を進めてください。今回はMiniMax H3の公開重みを使う再現経路です。別モデルへの変更はユーザーが選んだ場合に限ります。

## まず読む公開資料

1. https://huggingface.co/MiniMaxAI/MiniMax-H3 — 実行方式、公開範囲、利用条件。
2. https://github.com/K9i-0/madogiwa-multimedia-universe/blob/main/.claude/skills/minimax-h3-video/SKILL.md — MMUの実行経路。
3. 同ディレクトリのreferences/setup-and-cost.md、profiles.md、cli.md、prompt-design.md — 条件、固定プロファイル、CLI、入力設計。
4. scripts/colab_h3.pyと、そこから参照されるbuild_workflow.py・setup_cuda.py・run_workflow.py — 実装と引数。

相対参照はSKILL.mdのあるディレクトリが基準です。GitHub rawで取得するならblob/mainをraw.githubusercontent.comの同じリポジトリ・mainへ対応させてください。取得できない資料の引数や挙動を推測して実行せず、必要なファイルを特定して取得可能な方法を案内してください。

## 環境と入力

- Colab公式CLIまたは対応ノートブック、認証済みアカウント、利用可能CU、GPU割り当てを確認してください。勝手にプランやCUを購入しないでください。
- 今回の測定再現にはA100 1workerを使います。空きがなければ不足を報告し、入力とプロンプトを準備して待てる状態にします。異なるGPUの速度・料金を同じと扱わないでください。
- ローカルで動かす場合は対応するLinux/NVIDIA CUDA環境、VRAM/RAM、空きディスクを確認してください。Apple Siliconだけで同じ実行経路が動くと説明しないでください。
- モデル一式は約54GB。実行ディスクへ取得し、重みを有料Drive/GCSへ自動保存しないでください。
- キャラクターの同一性を満たす参照画像と、使用許可のある参照音声を使ってください。入力の順序とPicture/Audio番号を対応させてください。
- APIキーや認証トークンを会話へ貼らせないでください。公開重みと実行サービスの最新利用条件を確認してください。

## 生成と編集

1. 小さな場面のプロンプト、参照素材、発話順、動作、終了状態を用意します。多数のアクションを一度に詰めず、必要なら動作の節目で分割します。
2. R2V、480p-turboの固定プロファイルを選択。LoRAだけでなく8step、sampler、scheduler、video/audio shiftを揃えます。最新READMEの別モデルへ無断で置き換えません。
3. GPU・CU残高・消費率を記録。セットアップと生成を分けて時間を測ります。
4. 生成ジョブのIDを保存し、接続が切れたら同じジョブを確認します。完了不明のまま再送して二重生成しません。
5. 原本とログを回収し、ハッシュ、尺、解像度、fps、音声トラックを確認します。結果回収を確認したらGPUを停止します。
6. 顔・衣装・小道具・動作・セリフ・音声の重複・声質・リップシンクを確認します。デコードやASRだけで見た目・聴感まで合格としません。未確認なら範囲を明示します。
7. 原本480pを保持し、完成版へ一度だけ通常拡大します。横は1280×720。元の864:480の縦横比を維持し、必要なら小さな余白を足します。AI超解像を自動適用しません。
8. 字幕や正確な文字は完成解像度で編集します。発話に合わせ、原文と読みを分離し、クレジットを記録します。

## 費用と納品

動画当時の1.48 CU・約17円は一回の測定例です。現時点のCU単価と実消費で再計算し、追加購入額・既存枠の利用・サブスク料を分けてください。外部公開・投稿は依頼された場合のみ行います。

納品は完成動画、原本、採用プロンプト・入力・設定・再現コード、実測費用、確認済み事項と未確認事項。初版が再生可能になったら、追加監査を待たず先に絶対パスを提示し、必要な確認はその後に続けてください。
