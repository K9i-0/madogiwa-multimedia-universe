# 福ギュンとやめ太郎：エンジニアあるある — Shorts編集

Studio v22の公式サイト掲載済み結合完成版を使用。21章合計2247フレーム・24fps・映像93.625秒。元画面全体を720×1280の採用レイアウトへ配置し、音声は採用完成版のAACを再圧縮せず保持する。

v22のプロンプトは結合方法だけのメモのため、v1〜v21の実生成プロンプトを章順に `prompt.txt` へ集約した。対応するR2章動画のフレーム数合計が完成版と一致し、全21章の音声を完成版へ波形照合した結果、正規化相関はすべて1.0。AAC結合で生じる数十msの時刻差も照合結果から補正している。照合と章境界の根拠は `chapters.json` と `alignment.json`。

話者・台詞は各章のプロンプトに従い、長文は音声の無音区間で29枚の字幕カードへ分割した。表示名は「福ギュン」、第1章の実発話「福ちゃんやめちゃんです」はそのまま保持した。新たな台詞や音声生成は行っていない。

編集時刻の正本は `shorts-manifest.json`。技術監査は `technical-audit.json`、目視監査は `visual-audit.json`。全編デコード・元音声stream SHA一致と全字幕中間点・先頭末尾を検証する。音声波形の一致は同じ音源を使った証拠であり、人による通し試聴の実施を意味しない。
