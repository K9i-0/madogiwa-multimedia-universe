# 実況用立ち絵：たこさん・やめ太郎 v1

正典シートの3Dトイスタイルを維持した独自差分。ずんだもんの絵柄は参照せず、中央へ向かう配置と実況に必要な感情の種類のみ参考にした。

| ID | 表情・ポーズ |
|---|---|
| normal | 通常・腕を下げる |
| happy | 喜び・両手を広げる |
| surprise | 驚き・胸元に両手を上げる |
| worry | 困り・胸に手／問いかけ |
| bored | 呆れ・腕組み |
| angry | 怒り・腰に手 |
| sad | 落ち込み・手を低く寄せる |
| smug | 得意げ・片手で説明する |

各キャラクター8種。元画像は画面左向き。右配置ならそのまま、左配置は全レイヤーをまとめて左右反転する。文字は反転しない。

## 素材と口パク

- `<character>_<mood>.png`：内蔵image_gen生成の表情・ポーズ正本。
- `<character>_mouth_open.png`：共有の発話口を含む元画像。顔の該当領域だけを合成する。
- `yametaro_mouth_round.png`：驚き・困り・呆れ・怒り・落ち込み用の丸い発話口。
- `takosan_blink.png`：閉じ目の共有素材。やめ太郎は白レンズを固定し、瞳やまぶたを追加しない。
- `exports/`：口閉じ／口開きを合成した32枚の透過PNG。実際に動画で使うSpriteコンポーネントをRemotionで静止画書き出ししたもの。元画像は変更しない。
- 表情差分の生成プロンプトはgeneration.json。
- 原点：たこさん1164×1351、やめ太郎1024×1536。トリミングせず同じキャンバスで差し替える。

再書き出し：`03_SCRIPTS/sobaya_duo_explainer_20261010/remotion/`で`node export_sprites.mjs`。

そば屋解説動画：`03_SCRIPTS/sobaya_duo_explainer_20261010/`。自動口パク、左右反転、まばたき、全8種の採用例を含む。
