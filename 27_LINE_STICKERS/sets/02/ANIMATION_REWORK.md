# アニメーション再制作方針

実施済み：連続原画方式で8点を書き出し。最終仕様はREADMEとsource/animation-manifest.json。「ちゃんと働いてるか？」はB案へ変更、C案の段ボール椅子は「二流」へ転用。以下は再制作着手時点の記録。

2026-10-15：ユーザーから、第二弾の動作が不自然で無理に歪めたように見えるとの指摘。

## 原因

`tools/build.py` の `render_motion` は単一静止画へ局所的な変位場を適用し、`cv2.remap` で伸縮させていた。形式検証は通っても、関節の動き・輪郭・身体の剛性を保証しない。現在のGIF/APNGは採用しない。

## 第一弾に残っている記録

- `../01/source/sobaya/prompt.txt`：4列×3行の連続ポーズを1枚に生成する指定。頭・ジョッキ固定、前腕と手のみ動かす。
- `../01/source/sobaya/poses/00.png`〜`03.png`：実際に採用した4ポーズ。
- `../01/tools/build.mjs`：採用4ポーズを `0,1,2,3,2,1,0,1,2,3,2,1` の順で再生し、開始ポーズで休止。最終13フレーム。
- `../01/source/yotan/keyframes.png` と `prompt.txt`：3列×2行の6連続ポーズ。
- `../01/tools/motion.mjs`：切り出しと一部キャラの動き補間。第一弾すべてが同一方式ではない。

## 再制作

1. 採用済み静止原画と正典シートから、動かす部位・固定する部位を明示した連続ポーズシートを生成する。
2. 同一セル寸法で切り出し、共通の位置・倍率で整列。個別トリミングによる揺れを避ける。
3. 原画の顔・手・関節・小道具の連続性を目視確認。身体の局所ワープで不足ポーズを代用しない。
4. 文字を固定した独立レイヤーとして合成し、文字の穴・輪郭の透過を処理する。
5. 原画の順序と保持時間で動作と休止を作る。白・黒背景で実際の動きも確認する。

「乾杯！」は `reserve/02_kanpai/` に原画と旧書き出しを保存。「ちゃんと働いてるか？」への差し替えは静止画候補選定後。
