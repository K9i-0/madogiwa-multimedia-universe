# H3版「窓際族Tシャツ発表会」参照準備

2026-10-26ユーザー依頼。既存Three.js/Remotion版の採用Irodori音声を再利用し、ジョブズの発表を現代の画質で撮影したような実写基調の映像へ。今回は参照準備まで。H3・Colabは起動していない。

## 画の正本

- `refs/keynote_wide.png`: 2007年Macworldの低い客席目線、広い黒い舞台、大スクリーン、青い側面光を引き継いだ全景。
- `refs/keynote_medium.png`: 同じ衣装・舞台の話者寄り。仮面の穴・赤い模様・黒い額の点、黒髪と体格を維持。
- `refs/keynote_product.png`: 実物商品の白Tシャツを両手で見せる商品紹介。プリントは元の商品資料を最終正本とし、生成された小さな文字・人物細部を正典として再利用しない。
- `refs/sobaya_canonical.png` / `sobaya_face.jpg`: 人物同一性の正本。黒タートル、ジーンズ、グレーのスニーカーは本作の衣装指定。
- `refs/product_original.webp`: 既存版と同じ商品画像。SUZURI広告枠ではなく右側のシャツが商品。

画像はbuilt-in image_genで作成。正典の仮面・体格と衣装、舞台の連続性、手・商品を目視確認。全景・寄りの手には照明由来の暖色が少し残るため、H3では全露出肌をニュートラルグレーへ拘束する。商品印刷の文字精度は生成映像だけで保証しない。

巨大スクリーンは後から正確なスライドを載せられる無地。古い映像の低解像度・圧縮劣化を模倣せず、光学的な生地・仮面・肌の質感を使う。既存Three.jsの画は質感参照にしない。動画生成480p／完成720pの規定は維持し、「現代画質」は実写質感と撮影表現を意味する。

## 音声先行

32本すべて既存 `line_*_sobaya_large.wav` の採用ハッシュと一致。台詞約79.864秒。10本だけ末尾無音で2秒化、元WAV・話速・声質は変更しない。拍手、笑い、BGMを混ぜたマスターは入力しない。

`audio_manifest.json`に本文・元WAV・hash・発話尺・入力尺を記録。`python3 prepare_audio.py`で32本の入力を再構築できる（起動位置を問わない）。元WAVの同内容コピーはGit管理せず、追加パディングした入力だけ保持。

`chapter_plan.json`は2台詞ずつ16チャプター、約141.46秒の**仮割り**。既存の間を参考に17k+5へ丸めた。各入力は音声2本・各2秒以上・合計15秒未満。全編の最終キーフレームや着衣実演の動作境界はまだ確定していない。今回の3画像は共通舞台・人物・商品参照であり、16チャプターの始終点を完成させた扱いにしない。

H3には「声質サンプル」ではなく、今回実際に話すWAVとして渡す。`h3_prompt_template.txt`を使い、音声順と台詞順を一致させる。出力はモデル生成なので波形完全コピーを保証しない。入力・出力の発話、余分な語句、声質、間を比較する。

そば屋の仮面は固定。仮面を外したり柔らかい口へ変えず、発話と首・肩・手の演技を同期させる。人間の唇が見えないため、この作品だけで通常の唇のリップシンク精度を検証したことにはしない。
