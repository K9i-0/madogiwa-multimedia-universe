# Group B 編集記録

対象11本はすべて、採用済み元素材の長さが101秒以下で、Studioに生成プロンプトが存在する。最終版の全フレームを720×1280・24fpsへ編集し、元音声をビットストリームコピーで保持する。クレジットだけの末尾はなく、映画CMとハザードの告知ポスターは作品の一部として残した。

- `madogiwa-manner-class-question-1` は約100.5秒の全編を採用。1分41秒での切り出し指示として扱っていない。
- `sobaya-beer-battery` はR2素材とローカル第40話の採用済み `final_video.mp4` がSHA-256で一致。Studioにある後発の配役変更プロンプトを台詞へ転記せず、実際の福ギュン／よーたん版と `script_approach2_rich_30s.md`、元素材ASRを根拠に編集した。投稿作成者は `k9i`。
- `sobaya-yametaro-dismissal-notice` はアクションの効果音主体。プロンプトに台詞がなく、参照WAVの一致が低く、ASRも信頼できる台詞を返さないため、架空の字幕を追加していない。
- `madogiwa-zoku-monogatari-anime-opening` は音楽主体のオープニング。確認できない歌詞・台詞を追加していない。
- 通販の後付けナレーションと価格案内は参照WAVをASRで確認。価格と6缶パックは生成プロンプトの後編集指定とも照合。ナレーション冒頭の不確実な音節は省き、確認できた「持っているものは何ですか？」を字幕とした。商品説明の2区間は元素材ASRと章境界に基づく近似的な区切り。過去の実発話「福ちゃん」は保ち、話者ラベルは「福ギュン」。
- 映画CMの元H.264は最後のポスターでフィルタの再初期化を引き起こしたため、共通レンダーの `-reinit_filter 0` と厳密なフレーム数チェックで修正。修正版は945/945フレームで、最終ポスターとナレーション字幕を確認した。

監査は全体デコード、元音声とのハッシュ比較、寸法・fps・フレーム数確認、全字幕カードの中央フレームと代表・境界フレームの目視。全編を人間が聴取したという意味ではない。個別の `audit.json` と `technical-audit-group-b.json` / `visual-audit-group-b.json` が最終結果。動画・参照WAV・監査画像はGit管理外。

YouTubeメタデータは既存説明・クレジットを保持し、元動画リンクとShorts案内を追加。全11件は `privacyStatus: public`、`publishAt` なしで、自動投稿処理が実行時にアップロードする前提。
