# Tripoで窓際族を3Dにする — 初稿v1

2026-10-14制作。たこさん（VOICEVOX中国うさぎ・ノーマル61、速度1.1、音高0）＆やめ太郎（Irodori v4.1-Small、正典参照、seed7、本文CFG5、生成尺倍率0.70（Codex読み修復の2発話は0.85）、トリムなし）。

ユーザーとの台本検討を統合。冒頭のBlender版そば屋は第44話用の既存画像を利用し、「やめ太郎がCodexで作った」は劇中設定。そば屋の採用工程は縦832×1108・約8秒のWan動画から四方向を抽出した実例。たこさんは前後2画像の別経路。福ギュンは実写人物の再現で苦労した事例として短く紹介する。

追加支払いだけでなく制作時間を含めたコストの話は、本作の制作上の判断であり、汎用モデル全般の性能評価ではない。TripoのStudioとAPIは別契約。価格は1ドル160円の固定換算で、過去の回転動画推定$0.56＋Tripo実消費120 creditsを約282円と説明。入力画像・再生成・Codex等の利用料は別。

映像：採用済みExcel風画面、正典立ち絵、Three.jsで採用GLBをフレーム時刻から描画。公式サイトの実操作録画、AR入口の実画面、Flutter Sceneゲームの保存済みスクリーンショットを紹介。ARの実機撮影を行ったとは扱わない。

完成タイムライン：654.133秒／1280×720／30fps。発話・字幕・映像のフレーム正本は`remotion/src/edit-manifest.json`。
