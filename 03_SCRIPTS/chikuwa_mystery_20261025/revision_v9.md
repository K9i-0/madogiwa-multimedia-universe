# v9：観察の正しさと、研究者の残念さを分ける

## 台本セルフレビューと反映

| v8の課題 | v9の対応 |
|---|---|
| 実験へのツッコミが「採ればいい」の繰り返し | 味・弾力・焼き色を再現しても、生命活動だけ残る比較実験。結論語は発話に同期して初めて字幕表示。「一番大事なところが残っているのだ」 |
| 霜重の行動説明が長く、ボケが説明的 | 「警備員の制止＝研究への圧力」「お帰りください、なのだ」。飲酒説明を1発話に圧縮し、電話線と追加容疑の二段落ちは保持 |
| 北原の異常さが大きな陰謀用語に頼る | 検査に合格するほど容疑が深まる。正常終了音と3試料の表示を同期 |
| めたんが毎回留保し、暴走が弱い | 重複する留保を削除。後半は教科書を企業の宣伝資料に再分類し、給食と社会科教師を調査対象に拡張（発話前の字幕・資料への先出しを抑制） |
| ツッコミが説明の反復になりやすい | 検査の仕組みを復唱する発話と一般論の批判を差し替え。全85発話、ずんだもん24発話を維持 |
| 声の温度が一定 | 実験は少し得意げ、短いツッコミは抑揚控えめ、追加容疑は事務的、後半のめたんは熱量を上げる。「昨日食べた」は小声・遅め・長めの間 |
| 静止画の説明が続く | H3 480p Turboで森林、比較実験、T社門前、試薬検査、製造ラインの5本。生成音声は全てミュート |
| 汎用音では場所や行為が伝わりにくい | トレー、受付ベル、紙をめくる音、滴下、検査終了音、ローラー駆動音をオリジナル合成。会話を覆わない音量 |
| ヤマチクワの学名 | Daichikuwa humicola を分類画面と生態映像の注記に反映 |

## 構成上の保持事項

- ずんだもんは「天然ちくわは生き物、通常流通品は養殖」という世界内の常識人。人工説を積極的に支持する立場にしない。
- 毒ちくわは視聴者には明白、二人には見分けられない。市販で混入しない問題を調査の軸にする。
- 研究員間は「製法の再現→文献→現地確認失敗→出荷済み製品の検査→養殖説明の検証」で橋渡しする。
- ソバヤは天敵としてのみ登場。過去のだいちくわ映像は既採用の人物除去クロップ・低画質・原音なしを保持。
- 追加容疑は発話に合わせて初めて表示。末尾の「すべてさらけ出す」「まず服を着てから」で回収。
- 締め後の製造ライン、製造記録、政府の広報承認により、人工ちくわと隠蔽の実在を視聴者にのみ明かす。
