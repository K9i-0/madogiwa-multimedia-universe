# 品質改善記録

## 初回MP4 → 改善版v2

初回MP4を全尺デコードし、36資料画面・冒頭3例・クレジット・末尾の41点を実映像から抽出、7枚のコンタクトシートで目視。

見つけた問題と改善:
- 全身クロップへ背面、顔クロップへ2枚目の頭が混入 → 役割ごとに一枚だけを切り出す。
- シート2枚を横並びにすると細部が小さい → そば屋・たこさんを一枚ずつ大きく切り替える。
- API図の「コマンド」と音声図の「語句」が不自然に折り返す → 明示改行と短いラベルへ変更。
- 料金棒グラフに固定の高さを足していた → 価格に正比例する高さに修正。
- 冒頭クリップが文章途中で切れる可能性 → コント3.9秒、ニュース8.6秒、CM5.5秒に再配分。18秒の全長を維持。
- 例示タイトルが元ニュースの時計と重なる → 下部へ配置。
- 「作って、って頼む」の連続音 → 「作って、と頼む」に変更して該当音声のみ再生成。
- 末尾が静止画のまま終了 → 最後1秒を穏やかに背景色へフェード。

音声: 全104発話をWhisper-smallで期待文プロンプトなしに自動照合。固有名詞・数字・同音語にASR誤表記あり。VOICEVOXの生成読みと併せて確認。自動照合は通し試聴や聞き心地の保証ではない。

## 改善版v2 → 最終調整v3

- 混合音声の抽出・自動照合で1080pの読みを再点検。発音用の「せんはちじゅっピー」が「センワ…」に分割されていたため、数値表記「1080ピー」へ修正。480p・720pも数値表記へ統一し、クエリの読みを確認。表示字幕は変更しない。
- 冒頭のコント・ニュースは混合音声のASRで文末まで確認。CMの叫びは既存素材でもASRが不安定だったため、source 3.0–8.5秒のアクション区間へ移す。採用原音は保持。
- クレジットの静止時間を3秒延長し、音楽のフェードも新しい末尾に合わせる。

## 最終画面の追加調整

最終MP4の冒頭ニュースで、下部の紹介ラベルが元テロップの補足行に接近・重複していたため、そのクリップだけ追加ラベルを非表示にした。作品出典は概要欄へ保持。音声・本編は維持。冒頭25.8秒を再レンダーし、元映像の25.8秒のキーフレーム以降へストリームコピーで接続する。後半の画素同一性と全体フレーム数を確認する。
