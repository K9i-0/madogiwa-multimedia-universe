字幕移設の実例として、当初候補の「パクられた」を「タコゲーム」に入れ替えた。パクられたは全体候補からは除外していない。

## 共通仕様

- 720×1280、30fps。上部は作品タイトルだけ。下部のシリーズ名や追加宣伝コピーなし。
- 同期するぼかし背景。タイトルは白／淡いクリーム色、タコゲームはピンクの差し色。会話字幕は白文字＋メンバー色の縁取り＋細い黒外縁。名前表示は枠なしの白文字。タイトルは下線なし、大小2段の文字と控えめな影で構成。共通正本は `../00_TEMPLATES/subtitles/member-colors.ts`。
- 顔・道具・商品名を切らないよう、回ごとに本編のcontain/coverを選択。
- 各横版の音声をストリームコピー。映像の速度変更、音声の再生成、BGM追加なし。
- タコゲームの字幕移設では文言・改行を縦用に調整。「福ちゃん」表記は現行の「福ギュン」へ。韓国語原音は変更しない。
- 日本語フォントはmacOSのHiragino Sans。横版は全件保持。

## 成果物・再現

- `review.html`: 5本を再生できるローカル一覧。
- `delivery.json`: 出力、原版YouTube ID、尺、フレーム数、ハッシュ、監査結果。
- `metadata/`: YouTube登録用タイトル・説明・公開設定のJSON。作成のみで送信していない。
- `prepare_delivery.py`: 動画のデコード、PCM音声一致、フレーム数・字幕区間を検証し、一覧・メタデータ・監査画像を作る。
- 各作品の`remotion/src/shorts-manifest.json`が縦版のタイミング正本。`npm run render:shorts`でエピソード直下の`final_remotion_shorts_9x16.mp4`へ書き出す。
- 名探偵ヨータンのみ先に`shorts-clean.tsx`から文字なしの編集マスターを作る。`shorts-clean-manifest.json`は採用v22/v23と同じショット列。未採用v24音声は使用しない。

検証: 寸法・尺・全編デコード、横版とのPCM音声一致、代表字幕・タイトル・終了画面を確認。タコゲームは既存字幕の開始・終了フレームを全件保持。新規字幕は台本とASRによる時刻補助を使用。全編の直接試聴・精密な発話同期監査は未実施であり、機械検査の合格と区別する。

`out/`、生成MP4、ASR中間物はGit管理外。完成MP4は各エピソード直下に保持。
