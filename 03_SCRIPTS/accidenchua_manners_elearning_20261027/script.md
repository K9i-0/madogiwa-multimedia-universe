# 新入社員のための 窓際マナー研修

2026-10-27着手、2026-10-28書き出し。ユーザー採用：2b / 4b / 6b / 8a / 10a。H3生成およびRemotion完成編集の許可あり。

## 演出

架空企業アクシデンチュアの正式な新入社員教材として、最後まで真面目に進行する。
ナレーションはゆめテレアナウンサーの正典声。抑制された抑揚、均一な速さで、窓際族を淡々と小馬鹿にする。
登場人物は教材の事例を演じるそば屋、やめ太郎、福ギュン、たこさん。各H3映像に2人。
白・紺・青緑の研修画面、採用ACCIDENCHUAロゴ、章番号、3択、正解表示、学習ポイント、進捗バーをRemotionで制作する。
企業研修らしい軽い音楽とチャイムを自作。笑い声・バラエティ番組の効果音は入れない。

## 構成と台詞

台詞・読み・設問・選択肢の正本は `content.json`。
タイミングは音声生成後に `remotion/src/edit-manifest.json` の整数フレームへ確定する。

1. オープニング：ロゴ、受講案内、講座名、5項目の学習目標。「新入社員向けeラーニング／必修」。
2. 第1問「挨拶の基本」：福ギュンがそば屋へ「お疲れさまです」。正解B「本日もご在席ありがとうございます」。採用解説2bを全文使用。
3. 第2問「窓際での通行」：そば屋が外の工事を見ているところをたこさんが横切る。正解A「視界を遮らず、少しかがんで通る」。採用解説4bを全文使用。
4. 第3問「予定表の読み方」：福ギュンがやめ太郎の空白の予定へ会議を入れようとする。正解C「誰も頼まない理由を考える」。採用解説6bを全文使用。
5. 第4問「褒め方の配慮」：たこさんがやめ太郎に「やればできるんですね」。正解C「ありがとうございます」。採用解説8aを全文使用。
6. 第5問「研修後の実践」：福ギュンが仕事へ戻ろうとする隣で、やめ太郎は窓際で満足。正解B「三十分間、何もしない」。採用解説10aを全文使用。
7. 修了：5項目の学習完了表示。「実技：30分間、各自で実施」。締め「本日も、ご在席ありがとうございました」。実際に30分待つ動画にはしない。

各問：章カード→H3事例映像→3択の設問→考える間→正解→解説／ポイント表示。
設問は映像内の演出であり、クリックやユーザー回答を要求するアプリではない。
解説は生成映像の静止画と情報カードを使い、同じ芝居を不自然にループさせない。

## 完成台本（発話原稿）

### オープニング

ナレーション：アクシデンチュア、新入社員向けイーラーニング。窓際マナー研修へようこそ。

ナレーション：本研修では、五つの事例を通して、窓際社員との適切な接し方を学びます。

ナレーション：映像をご覧になり、もっとも適切な対応を選んでください。

### 第1問　挨拶の基本

事例映像（H3）：

- 福ギュン「そば屋さん、お疲れさまです！」
- そば屋「まだ、何もしてません。」

ナレーション：第一問。この場で、もっとも適切な挨拶はどれでしょうか。

- A：お疲れさまです
- B：本日もご在席ありがとうございます（正解）
- C：お仕事は順調ですか

解説ナレーション：勤務実態が確認できない場合は、確認できた事実を伝えましょう。『本日もご在席ありがとうございます』であれば、少なくとも席にはいますので、嘘にはなりません。

### 第2問　窓際での通行

事例映像（H3）：

- そば屋「あ、見えない。今、工事の大事なところです。」

ナレーション：第二問。窓際社員の前を通るとき、適切な対応はどれでしょうか。

- A：視界を遮らず、少しかがんで通る（正解）
- B：仕事の進捗を尋ねてから通る
- C：一緒に仕事の未来を語る

解説ナレーション：担当業務の進捗は把握していませんが、向かいのビルの工事には大変詳しくなっています。せっかく関心を持てるものが見つかりましたので、邪魔をしないようにしましょう。

### 第3問　予定表の読み方

事例映像（H3）：

- 福ギュン「午後、予定がないですね。会議、入れますね。」
- やめ太郎「なんで、そうなるんや。」

ナレーション：第三問。予定表に空欄があったら、まず何をすべきでしょうか。

- A：すぐに会議招待を送る
- B：暇かどうかを尋ねる
- C：誰も頼まない理由を考える（正解）

解説ナレーション：予定が空いているのは、皆さんの依頼を待っているからではありません。周囲が依頼を諦めた結果です。まずは、なぜ誰も頼んでいないのかを考えましょう。

### 第4問　褒め方の配慮

事例映像（H3）：

- たこさん「すごい。やれば、できるんですね。」
- やめ太郎「そこには、触れんといて。」

ナレーション：第四問。仕事ができた社員に、適切なひと言はどれでしょうか。

- A：やればできるんですね
- B：では、毎回お願いします
- C：ありがとうございます（正解）

解説ナレーション：『やればできるんですね』という褒め方は控えましょう。『では、なぜ普段やらないのか』という話になってしまいます。ご本人が説明できないことを、聞き出してはいけません。

### 第5問　研修後の実践

事例映像（H3）：

- 福ギュン「研修も終わったし、仕事に戻ります！」
- やめ太郎「今日も、あっという間やったな。」

ナレーション：第五問。研修後、まず行うことはどれでしょうか。

- A：仕事の遅れを取り戻す
- B：三十分間、何もしない（正解）
- C：改善案を提案する

解説ナレーション：これから30分間、何もせずにお過ごしください。長く感じても問題ありません。窓際族は、これを一日続けたあとに『今日もあっという間だった』と言います。

### 受講完了

ナレーション：以上で、窓際マナー研修を終了します。実技は、各自で実施してください。

ナレーション：本日も、ご在席ありがとうございました。
