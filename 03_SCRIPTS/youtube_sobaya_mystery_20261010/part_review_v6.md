# パート別見直し v6

全体を「観測 → 初歩的な推論ミス → 世紀の発見として発表」に整理。複数の理論を接続する説明を削り、116発話・10分33.567秒へ短縮した。

| パート | 改善内容と狙い |
| --- | --- |
| 導入 | 真面目な番組挨拶、ずんだもんの指摘を無視する間、黒いシルエットを維持。正体を隠す。 |
| 形態 | 大小モニターへ同じ映像を置き、画面上の人影へ定規を当てる図に変更。「大画面だと大きい」を映像で見せる。 |
| UMA比較 | ビッグフット・イエティ・SOBAYAへ「腕2本／脚2本」を並記。余分な起源説の分岐説明を削除。 |
| 証拠解析 | 同じ映像を3回再生して3件の検証とする図。同語反復の結論「正体が分からない → 何者か分からない」を循環図にする。 |
| 古代の門 | 門を通れば反対側へ出る追試を図解。窓の起源をめぐる余分な説明を削る。 |
| 儀式 | 聞き取れない言語の解釈、3年待機、液体の受領という単純な観察を残し、言い換えを削る。 |
| 古代文明 | アトランティスは水中、容器にも液体、ゆえに関連という比較に一本化。到着前からあったため遺跡と認定。装置の稼働を『ラピュタ』で裏づける。 |
| 一度だけの作品ネタ | 霜重の参考文献に作品名と感想「すごかった」。ずんだもん「参考文献が、テレビの感想文なのだ。現地を調べろ。」。直後の配線への反応は穏当な質問へ変更し、辛辣さを連打しない。 |
| 宇宙 | エリア51との共通点は「中身がよく分からない」。円筒を振ったちゃぷちゃぷ音を地球人への応答と解釈。開封せず国際会議に提出。複雑な推進器官の説明や別の映画ネタは使わない。 |
| 研究総括 | 原人・古代人・宇宙人を無理に一つの説へ統合しない。「今後の研究を進めるためには、これから研究を進める必要がある」で真顔の総括。 |
| 正体・締め | 人事部から「うちの社員です」。ここで鮮明な映像と本来の名称を解禁。窓際社員のオチと「マドギワでの生息を希望される方」への登録案内を維持。 |

## 演出の統一

- ずんだもんは基本的に質問・観察で進行し、作品を研究根拠にする場面などの節目で正気に戻る。
- 霜重は「しもじゅう」。架空の研究者6名・6組織を維持。
- 生成画像には想像復元・イメージの表示を付け、実写の証拠記録と区別する。
- 正体判明まで、台詞に「そば屋」「クローン」「ビール」を出さない。
- 林の同語反復は本作用の創作であり、実在人物の発言引用ではない。
