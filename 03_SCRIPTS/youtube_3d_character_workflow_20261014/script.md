# Tripoで窓際族を3Dにする — 完成版v2

2026-10-14の検討とv1視聴後の改修依頼を反映。完成例と到達点を先に見せ、実際の入力→Tripo→修正→動作→活用の順で進める。料金・契約・一般論は具体的な生成手順のあとへ移動。

登場：やめ太郎（正典Irodori v4.1-Small、seed7）、たこさん（VOICEVOX中国うさぎ・ノーマル61、速度1.1・音高0）。新規・修復25発話、再利用66発話。v1は別ファイルとGit履歴に保持。

冒頭のBlender版そば屋の制作担当は劇中設定。過去の回転動画・入力画像・モデル・修正資料は実素材を使用。そば屋は縦832×1108のWan動画から四方向を抽出。たこさんは前後2画像。福ギュンは実写人物の再現を調整した事例。

料金は過去の制作記録に基づく2工程の例。Wan推定$0.56＋Tripo120 credits、1 credit=$0.01、1ドル160円で約282円。入力画像・再生成・開発エージェント等は含まない。StudioとAPIは別。

API指示と端末の表示は、リポジトリの実装に沿った説明用の操作例。今回新たな有料生成を送信した映像とは扱わない。

タイムライン：642.767秒／1280×720／30fps。フレーム正本：`remotion/src/edit-manifest-v2.json`。
