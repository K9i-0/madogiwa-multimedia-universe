# ギュンレボ 土星リング・ライブ

ユーザー承認: 土星リング・ライブ、宇宙人観客役はゆめみん・たこさん・そば屋。30秒以内、約10秒単位の大きな場面転換。元動画の歌声・伴奏を使用。

## 制作設計
- 完成25秒。参照動画5秒＋出力25秒＝30秒のAPI上限へ収め、一つのWanタスク内で3場面を生成。
- 0–8秒: 福ギュンの胸上で5秒歌唱、マイクを左手で握り続ける。その後透明な浮遊ステージへ引く。
- 8–17秒: 宇宙人観客席。ゆめみんは短い鼻先でペンライトを保持（手足を生やさない）。たこさんは6本の下半身触手と2本の丸い手を維持して応援。そば屋は白い仮面とグレー肌・白Tシャツを保ち、低重力で一回転。
- 17–25秒: 福ギュンの背後から宇宙へ引き、土星の輪全体がライブ会場であることを見せる。光のウェーブ。
- 元動画の77–102秒を連続使用。歌唱アップ参照は77–82秒を出力0–5秒へ割り当てる。
- 比率16:9、生成480P、完成1280×720、原音の速度変更なし。
- 前回のマイク浮遊を防ぐため、握り・指の接触・手首とマイクの剛体的な連動・持ち替えなしを実送信プロンプトへ明記。生成後、可視マイク区間を細かく静止画化して確認する。
- 同期方式メタデータはwan_generated_lip_syncだが、実際の音声はユーザー指定の原曲を採用。新規生成音声は歓声のみ。声の再生成や全面リップシンク合格を意味しない。
- 見積: 480Pの0.035 USD/秒 × (入力5秒＋出力25秒)＝1.05 USD。2026-10-22公式情報確認。実請求未照合。
