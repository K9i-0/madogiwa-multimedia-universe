# 連続原画・透過・演技

## 原画生成と採用

採用済み絵柄と現在のキャラクターシートを役割別に参照し、編集を重ねて荒れた候補画像を唯一の参照にしない。生成は利用環境の `imagegen` に従う。Codexでは内蔵画像生成を使用し、Claude Code等では`codex-imagegen`スキルで同じ内蔵画像生成を呼び出し、勝手に有料APIや別モデルへ切り替えない。

必要なのは演技の意図、動く部位と静止物、コマ順、同一カメラ・倍率、余白、顔と小道具の連続性。3列×2行は例であり、セル数や動作量を全件で固定しない。

```text
参照1＝採用構図と絵柄、参照2＝キャラクター同一性。
透明背景の連続原画シート。例：3列×2行、等寸法セル、左上からの読み順。
文字・番号・罫線なし。全セル同じカメラ、倍率、静止背景の位置。
顔・衣装・小道具の寸法を維持し、輪郭や腕が隣セルへはみ出さない。
演技の意図：[気分・相手との関係]。
動作：[開始→中間→着地]。肩・胸・腕・頭の接続を保つ。
固定するもの：[背景・文字・動かない小道具]。
終端：[読ませたい姿勢]。不要な前進、顔だけの拡大、仮面の変形を避ける。
```

そば屋では丸い目、赤い模様、額の点、**丸端の小さい横長の黒い口**を確認する。笑顔の意図でも仮面を勝手に口角のある笑顔へ変えない。白Tの乳首状の突起・点影は現行正典に合わせて除く。そば屋の基準を他キャラの顔へ適用しない。

生成後は全コマを見て顔、手の本数、関節、服、物の消失・再出現を検査する。使えないコマは選外にし、必要なら動作部分の中間原画を追加生成する。原画数と納品フレーム数は同じでなくてよい。

## 切り出し・整列・固定背景

1. 実際の寸法とセル境界を確認する。正方形／均等割りを指定しても出力が守るとは限らない。不均等な余白があれば切り出し座標を記録する。
2. 同じ座標系へ揃え、机・窓・床などの静止部分を基準に平行移動で整列する。動く顔や手を基準にすると意図した演技が相殺される。
3. **全採用コマを覆う共通のcropと倍率**で出力する。コマごとのbboxに合わせて拡大縮小しない。
4. 固定背景を合成するなら動く部位の全姿勢を覆うマスクを作る。窓まで広く動作領域へ含めず、人物・息等は分ける。座標は構図ごとに見直す。
5. 以前の手足が露出する背景をコピーすると残像になる。安全な境界がなければ背景原画を用意するか、合成を見送り別の改善を選ぶ。継ぎ目が出た試作を完成版へ入れない。

全体の剛体移動・回転・倍率変更は、それ自体が狙った演技の場合に使える。標準の人物演技を身体の局所ワープやオプティカルフローだけで作らない。第一弾に補間処理が存在することと、現在の推奨制作方式は区別する。

## 文字と透過

- 新規文字は透過RGBAへ正確な文字列を描き、固定レイヤーとして重ねる。フォント変更時は実寸の可読性と改行位置も見る。
- 白地文字から抜く場合は黒インクの被覆率でアルファを作る。「口」「日」等の閉じた白も抜く。背景からの連結領域だけの除去では穴が残る。
- 白T・仮面・目の白・ビールの泡を背景と一括で消さない。人物外形と背景を分け、半透明輪郭に混ざった背景色を補正する。
- きれいなRGBAは再マット処理しない。不透明内部が253/254等の場合の補正は生成アルファを確認して適用する。意図的な半透明の息まで不透明化しない。
- 文字と独立した黒い記号には必要に応じて細い白フチ。黒背景で読め、白背景で太りすぎないことを確認する。
- 隣セルの破片、文字下の残り、髪の補間残像を対象限定で除く。小連結成分の全削除で雪・汗・星を誤消去しない。

参考：第一弾 `27_LINE_STICKERS/sets/01/tools/matte.py`、第二弾 `27_LINE_STICKERS/sets/02/tools/build.py` の `clean`・`caption`・`outline`・`prepare`。

## 再生と確認

予備動作→動作→読ませる間をコマ順と保持時間で作る。第二弾の3秒・1回再生は採用例で、LINE規格内で演技に合わせる。同じ画像の連続複製はAPNGで統合されることがあり、必要フレーム数の水増しに使えない。

GIFは確認用に繰り返しても、納品APNGは1回再生にできる。ループを閉じるためだけの逆再生や、先頭・末尾一致の機械的要求を入れない。先頭は静止表示にも使われるため、1枚でもセリフと絵の意図が伝わるか見る。

最終APNGをデコードして確認する。フレーム数が違う一覧はフレーム番号で揃えず経過時間で同期する。白黒両背景・実寸・輪郭拡大で文字の穴、顔、手、静止物、物の状態、継ぎ目、休止時間を見る。元原画だけの確認で完成扱いにしない。
