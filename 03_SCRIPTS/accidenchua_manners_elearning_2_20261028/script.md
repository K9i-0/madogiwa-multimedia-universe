# 窓際マナー研修 第二弾・メガジョッキ編

## 制作指定

- ユーザー採用：小さいジョッキはすぐ飲み干される。職場に続いて酒席でも干すのは重ねて失礼、という架空のマナー。
- H3 480p Turboで、そば屋と福ギュンの演技を作る。正典の顔・仮面・声を維持し、実写の居酒屋と実写役者の撮影表現へ統一する。
- 参考：古屋雄作チャンネル「人を怒らせる様々な『はい』」 https://www.youtube.com/watch?v=-ZwHP9T_wCc
- 参考動画をローカル取得し、4:3、青紫の抽象CG導入、青い章タイトル、固定カメラ、控えめな右下テロップを確認。参考の映像・声・曲は完成品へ流用しない。
- 完成4:3・960×720、24fps。生成640×480。低めのコントラスト、少し甘い輪郭、控えめな色にじみで古いDVDの雰囲気を作る。強いVHS破損や激しい走査線は加えない。
- 導入は独自制作の短いシンセ／電子ピアノの教材風BGM。演技中は音楽を止める。
- ナレーションは本作専用のIrodori音声デザイン。参考動画の声やニュース専用の声を模倣・固定流用しない。
- 文字・UI・図解・音楽・最終ミックスはRemotionと再現コードで制作。最終タイミングは `remotion/src/edit-manifest.json` を正本にする。

## 構成

1. 約5秒の導入。青紫の単純な立体図形、白い明朝文字「窓際マナー研修」、小見出し「飲み会での気配り」。
2. 居酒屋の固定二人芝居。福ギュンの手元には普通サイズのジョッキ、そば屋の前には頭より大きいメガジョッキ。福ギュンが空いた手でメガジョッキを丁寧に示す。ジョッキを持ち替えず、大きさと数量を安定させる。全員成人。飲酒動作は行わず、そば屋の仮面は固定したまま。
   - 福ギュン「そば屋さんには、こちらをご用意しました。」
   - そば屋「なんで、僕だけこんなに大きいんですか。」
   - 福ギュンが当然のこととして微笑み、そば屋が普通サイズのジョッキと見比べる。間を残す。
3. 青い章カード「メガジョッキ」。
4. 安っぽい研修UIで解説。実演の静止画と通常／メガの簡素な比較図。ナレーション文言は `content.json` の4ブロック。
5. 「職場に続いて、酒席でも干さない。」のまとめを表示して短い音楽とフェード。

## 保持する人物条件

福ギュン：正典写真とシートの本人の顔。綺麗な肌と自然な年齢・笑いジワを維持し、余計な斑点やそばかすは加えない。

そば屋：白い固定仮面、短い黒髪、露出部全体のニュートラルグレー肌、大柄な筋肉質の体格。白Tの自然な胸筋・布のシワを維持し、乳首状の突起・輪郭・対の点状陰影を除く。

## 音声・生成記録

俳優音声は `VOICE_CAST.md` のモデル・参照WAV・seedを使用。そば屋はLarge＋monsterize、福ギュンはSmall。各台詞の実測尺と設定は `voice-records.json`。元のH3音声と正典入力WAVは別々に保持し、必要な差し替えは編集記録へ明記する。

v1のH3はセリフをASRで確認したが、ジョッキが3個になり、白Tに点状陰影があったため不採用。v2は内蔵imagegenによる実演の基準画像を新規作成し、正しい2個のジョッキと人物を固定してH3へ渡す。画像生成の実送信本文は `prompt_image_mega_scene_v2.txt`。人物参照は正典のそば屋・福ギュンシートと福ギュン写真。過去出力・過去入力は上書きしない。

v2では人物とジョッキを維持できた。白Tに残った一か所の黒点だけを `retouch_shirt.py` で小領域追跡・局所補間し、原本と音声を保持。311フレームのうち、点が検出された138フレームを補修した。顔・仮面・ジョッキ・胸の輪郭は補修対象外。音声はH3埋め込み音声を使用し、差し替えなし。

## 使用素材・クレジット用情報

- 出演：そば屋、福ギュン（正典参照によるH3生成の架空の演技）。
- 音声参照とナレーション：Irodori-TTS。ナレーションは本作用のオリジナル音声デザイン。
- 音楽：「窓際マナー研修・導入ジングル」。本作用の独自合成曲。外部楽曲・参考動画の音源は不使用。楽譜相当の音符・音色・ミックス指定は `prepare_edit.py`。
- 画像：内蔵imagegenによる正典参照の実演基準画像。
- 公開・投稿は今回の制作には含めない。参考映像の取得物、生成動画、中間音声、監査画像はGit対象外。

## FB1：研修調の解説へ改稿

- 「飲み干す」が職場で人を「干す」ことを連想させる理由を、受講者への語りかけから説明する。「重ねて失礼」から相手の立場への配慮へつなぐ。
- 締めを「この違いが、できる社会人の気配りです。」へ変更。
- explain03 / explain04を同じナレーター参照WAVからIrodori v4 Largeで再収録し、採用音声を `explain03_fb1.wav` / `explain04_fb1.wav` に保存。元音声・前版動画は保持。芝居のH3再生成は行わない。
- 解説画面は「酒席の飲み干す → 職場で干す」の連想から、「重ねて失礼」「相手のお立場に配慮」へ順に切り替える。
