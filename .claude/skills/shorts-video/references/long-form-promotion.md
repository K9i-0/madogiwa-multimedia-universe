# 長めの動画の本編誘導用ショート

## 切り出し範囲を選んでもらう

本編の台本・発話タイミング・実映像から、2〜3候補を提示する。各候補に開始〜終了、完成予定尺（終了案内を含む）、最後の台詞、何が気になって本編を見たくなるかを添え、推奨候補を示す。ユーザーの選択前に範囲を確定して全編レンダーや投稿へ進まない。既に採用された範囲は再確認しない。

- 冒頭の茶番だけで終える案と、何を解説する動画か分かる紹介まで含める案を比較する。オチだけで満足してしまうなら紹介まで延ばす。
- 冒頭が適さなければ途中の印象的な実例・疑問も候補にする。前提がなくても理解でき、答えや詳しい方法を本編で見たくなる切れ目を選ぶ。
- セリフの途中を切って無理に引っ張らない。意味と呼吸の切れ目に合わせ、次の発話の頭が混入しない整数フレームで終える。
- 「続きは本編で」等を最後に短く表示する。今回の採用例は最終画面を2秒静止し、台詞の後のBGMだけフェード。2秒や特定の文言は固定条件ではない。

採用例：LINEスタンプ解説は、茶番だけの39.53秒から、挨拶と「二つを作る中で分かったコツを紹介します」までの63.43秒へ延長し、案内2秒を足して65.43秒とした。これは全作品共通の切り出し位置ではない。

## 解説は縦画面向けにレイヤーを組み直す

Remotion等で元のレイヤーがある場合、横完成動画全体を小さく収めるより、解説画面・立ち絵・字幕を分離して再配置する方式を第一候補にする。

- 左右の立ち絵用に取っていた余白を除き、資料・図解・実演画面を幅いっぱいに大きく表示する。意味のあるLINE/Outlook等の画面内UIや文字は保つ。不要な外側の番組枠だけを省ける。
- 実況の2人は解説画面の下へ移す。表情・口パク・まばたき・話者との同期は元のデータを使う。
- タイトル、資料、立ち絵、字幕の領域を分ける。字幕は会話レイヤーから再描画し、元字幕と二重にしない。メンバー色は共通正本を使う。
- 全資料・最長字幕で欠けと重なりを確認する。YouTubeの操作UIや下部表示とも競合しないよう、実際の表示を踏まえて調整する。今回の座標を全作品へ固定しない。
- 焼き込み動画しかない場合は、無理に人物を切り抜かず、既存の全幅横動画方式や安全なクロップを選ぶ。

実装例（リポジトリルートから）：`03_SCRIPTS/youtube_line_stickers_20261015/remotion/src/Explainer.tsx` の `portrait` 分岐、`DuoSprite.tsx`、`PortraitTrial.tsx`。元の演技データを使ったまま資料を約1.78倍に表示した。`build_portrait_trial.py` と `portrait_trial_audit.json` に書き出し・検証例がある。例の固有タイムコードは新作にコピーしない。

レイアウトを試す場合は別ファイルでプレビューを渡す。「見てから判断」なら予約済み動画は触らない。採用後に正本・再生成の既定経路・監査記録を更新し、旧版を退避する。

## 音声・成果物

採用本編の音声と発話タイミングを保持する。映像だけのレイアウト変更なら採用済みショートのAACをコピーしてhash一致を確認する。終了案内を追加する際は次の発話を入れず、余韻だけフェードして無音を足す。再符号化した場合はAAC一致を主張せず、発話部分PCMの一致など検証方法を明記する。

完成尺、切り出し元範囲、静止区間、音声処理、採用レイアウト、hash、現行動画IDを記録する。監査は全編デコードと全字幕カード・代表資料・終了画面の確認を行い、静止画確認と通し試聴を区別する。X用の元アスペクト比抜粋は依頼がある場合に別途用意し、ショートの変更で勝手に範囲を変えない。

## 予約公開・予約済み版の差し替え

投稿指示があるときに [madogiwa-studio](../../madogiwa-studio/SKILL.md) のYouTube直接アップロード手順を使う。誘導用ショートはYouTubeのみとし、Studioや週次キューへ自動登録しない。既存の投稿記録とhashで重複を確認する。

- 日時・タイムゾーンを確定し、現在より未来であることを確認する。未指定の時刻を推測して投稿しない。本編と同時刻の指定は引き継ぐ。
- `status.privacyStatus: private` と `status.publishAt` を設定する。予約まで完全非公開にする場合、限定公開やプレミア公開で代用しない。
- 公開時刻を過ぎていたら、勝手に即時公開へ変更せずユーザーに希望を聞く。
- 概要欄へ現行の本編URLと実使用素材のクレジットを入れる。Shortsの関連動画設定は対応するUIと利用条件を確認し、未設定ならその旨を記録する。本編をリンク設定のためだけに限定公開へ変えない。
- アップロード後に公式チャンネル、処理完了、非公開、予約日時、タイトル・概要欄を再取得して確認する。APIの投稿成功と処理完了を区別する。
- 予約済み動画の映像差し替えは、新版を別IDへ投稿し、処理完了と予約を確認してから旧版の予約を解除し非公開で保持する。明示依頼なしに削除しない。本編はショート差し替えだけなら変更しない。
- 旧版はstatus更新で `publishAt` を省いて予約解除し、非公開を維持する。更新直後の返却値には古い予約が残る場合があるため、短い間隔で新しく取得した状態で解除を確認する。状態が確定しないまま別IDのアップロードを繰り返さない。
- 旧投稿記録は `superseded` として退避し、新ID・hash・予約状態を現行記録と案内リンクへ反映する。外部共有済みURLが変わることも報告する。

YouTubeの尺・縦横比・関連動画・予約条件を確認する際は公式ヘルプを使う。過去の「60秒上限」等を固定ルールとして引き継がない。
