# めたんのミステリー研究所 第2回：ちくわ人工物説

採用方針v5：ずんだもんは「ちくわは生き物」という世界の常識を最後まで守る。めたんと研究員が、観察・実験から人工ちくわ流通説を唱え、さらに陰謀論へ飛躍する。分類・生態・研究内容・T社は作品内の架空設定。


## intro / opening

**めたん**：海に生息し、山にも分布する、身近な生き物。ちくわ。

**ずんだもん**：秋は山のちくわがおいしいのだ。

**めたん**：しかし今、そのちくわに、作りものが紛れ込んでいるという疑惑が持ち上がっているわ。


## intro / claim

**めたん**：魚の肉をすり潰し、棒に巻いて焼く。それを、本物のちくわとして売っているというの。

**ずんだもん**：なんでそんなことするのだ。ちくわを採ればいいのだ。


## intro / sightings

**めたん**：そして、この問題を調べる過程で、研究チームは奇妙な共通点に気づいたわ。

**めたん**：海での水揚げ。山での採集。そして、毒ちくわ事件。すべての現場に、同じ人物がいるの。

**ずんだもん**：またこいつなのだ。


## intro / sobaya

**めたん**：前回、企業に所属する社員であることが判明した、未確認生物ソバヤ。

**ずんだもん**：社員だと分かったなら、そろそろ未確認を外してやるのだ。


## intro / title

**めたん**：なぜ、ちくわのあるところにソバヤが現れるのか。そして、人工ちくわとは何なのか。今日は、この謎に迫るわ。

**めたん**：めたんのミステリー研究所へ、ようこそ。このチャンネルでは、身近な常識に潜む謎を、研究員たちの調査とともに追っていきます。今夜のテーマは、あなたが食べたちくわは、本当にちくわだったのか。


## biology / ranks

**めたん**：まず、一般的な分類を確認しましょう。ちくわは、管状動物門、真管綱、チクワ目に属する動物よ。


## biology / species

**めたん**：海産のウミチクワと、山産のヤマチクワは、共通祖先から分かれた別の種とされているわ。

**ずんだもん**：このあたりは義務教育でみんな習うのだ。ちくわが生き物なんて、いまさら説明することでもないのだ。


## biology / anatomy

**めたん**：中央の穴は、水や空気を通す通水腔。体内の細い水路とつながり、物質の交換を助けているの。

**めたん**：明確な頭部を持たず、神経が身体全体に広がる。初期の動物に見られる、単純な体制を残しているわ。

**ずんだもん**：昔の特徴は残っていても、ちくわなりに進化は続けているのだ。


## experiment / nakaguchi

**めたん**：ところが広域未確認生物研究所の中口研究員は、市販のちくわに、生き物ではないものが混ざっていると主張しているわ。


## experiment / analysis

**めたん**：購入したちくわを分析し、魚肉に似たタンパク質と、加熱で固まった組織を確認。原料は魚ではないかと考えたの。

**ずんだもん**：ちくわを調べたのだから、ちくわの成分なのだ。焼いたちくわは、当然、加熱されているのだ。


## experiment / process

**めたん**：そこで魚のすり身に塩を加えて練り、棒に巻いて加熱。ちくわに似た、弾力のある筒状の食品を再現したわ。

**ずんだもん**：魚を潰して、ちくわの替え玉を作ったのだ？ その手間で、本物を採ってくるのだ。

**めたん**：研究員が恐れているのは、この替え玉が、本物に混ぜて売られている可能性よ。私たちは、気づかないまま食べているのかもしれない。

**ずんだもん**：そんなものを混ぜられたら困るのだ。でも、研究員が作った偽物を、店で売っている証拠にはできないのだ。


## experiment / manufacturers

**めたん**：中口研究員は、購入品の一部に、不自然なほど均一な穴と、継ぎ目のような跡があると指摘したわ。生き物の身体ではなく、型で作った痕跡ではないかと。

**ずんだもん**：形のいいちくわを選んで袋に詰めたら、偽造の容疑をかけられたのだ。


## experiment / network

**めたん**：もし偽物が本物に混ざり、同じ売り場に並んでいたら、食卓に届くころには誰も疑わない。研究員は、このすり替えを支える国家規模の組織があると考えたわ。

**ずんだもん**：穴がきれいなだけで、国家ぐるみの食品偽装にするな。

**めたん**：ちくわという生物を模倣し、日常の食卓へ送り込む。その本当の目的は、まだ分かっていないの。

**ずんだもん**：目的の前に、流通しているという証拠が足りないのだ。


## history / shimoju

**めたん**：一方、狭間文明研究所の霜重研究員は、魚肉を竹に巻いて焼く方法が、古い文献に記されていることを確認したわ。

**ずんだもん**：昔にも、ちくわの偽物を作る暇な人がいたのだな。

**めたん**：時代の異なる資料にも、同じような工程がある。霜重研究員は、人工ちくわの製造が長く続いてきた証拠と考えたの。

**ずんだもん**：こんな古文書の画像、いまならAIでいくらでも捏造できるのだ。現物は確認したのだ？


## history / oldnetwork

**めたん**：霜重研究員は、画像に残る製法が、何度も政権交代を生き延びている点に注目。政府より長く存在する組織を疑ったわ。

**ずんだもん**：現物の確認はどうしたのだ。レシピが長持ちしただけで、秘密結社を作るな。


## infiltration / factory

**ずんだもん**：ちくわを洗って袋に詰める工場に、何の闇があるのだ。

**ずんだもん**：まず、取材の約束はしていたのだ？
