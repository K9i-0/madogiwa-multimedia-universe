# THE SOBAYA — BEHIND THE CHAOS

2026-10-28: ユーザー許可に基づく特撮NG集。既存Wan失敗テイクとH3追加芝居4本で構成。公開は未依頼。

## 構成
1. 遅すぎる空中移動 → ワイヤーで吊られたそば屋／福ギュンのカット。
2. タンクの縮小 → 大小の撮影用タンクを比較。
3. 盛大にビールをこぼす → ずぶ濡れの2人、そば屋が謝る。
4. 休憩 → 普通のジョッキでも仮面に当たりこぼす。福ギュンが黙って台本を閉じる。

2人は普段の身長比170:180。街・工場はミニチュア、外側は普通の撮影スタジオ。実写福ギュンは正典写真、そば屋は現行白Tシート準拠。タンクは大小とも正典の窓際スーパーつらいラベルを使用する（初稿の汎用マークから修正）。

## 音声と入力
台詞はdialogue.json。正典Irodori参照から生成した各ch*_*.wavをH3へ入力。福ギュンSmall seed100、そば屋Large seed42＋正典monsterize。H3出力音声を採用し、参照WAVの波形同期は保証しない。BGM追加なし。

## 生成
H3 R2V、480p Turbo、864×480、24fps、8steps、euler/beta、SigmaShift12/3、純正Ref2VA＋固定Turbo LoRA。1章1場面画像、台詞WAV1〜2本。A100 1workerで4章順次。実入力はch01〜04.jsonとch01〜04_prompt.txt。完成は720p、縦横比保持で一度だけLanczos拡大。
