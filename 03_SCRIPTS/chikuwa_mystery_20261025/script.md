# めたんのミステリー研究所 第2回：ちくわ人工物説

採用方針：観察・実験・文献調査は妥当。目的や背後関係の推論で陰謀論へ飛躍する。分類・生態・研究内容・T社は作品内の架空設定。

**めたん**：しかし、その正体について、私たちの常識を根底から覆す仮説が提唱されているわ。


## intro / claim

**ずんだもん**：なんでそんなことするのだ。ちくわを採ればいいのだ。


## intro / sightings

**めたん**：海での水揚げ。山での採集。そして、毒ちくわ事件。すべての現場に、同じ人物がいるの。

**ずんだもん**：またこいつなのだ。

## intro / title

## biology / ranks

**めたん**：まず、一般的な分類を確認しましょう。ちくわは、管状動物門、真管綱、チクワ目に属する動物よ。


## biology / species

**めたん**：海産のウミチクワと、山産のヤマチクワは、共通祖先から分かれた別の種とされているわ。

**ずんだもん**：山のちくわは乾燥に弱いから、湿った落ち葉の下を探すのだ。


## biology / anatomy

**めたん**：中央の穴は、水や空気を通す通水腔。体内の細い水路とつながり、物質の交換を助けているの。

**めたん**：明確な頭部を持たず、神経が身体全体に広がる。初期の動物に見られる、単純な体制を残しているわ。

**ずんだもん**：昔の特徴は残っていても、ちくわなりに進化は続けているのだ。


## experiment / nakaguchi

**めたん**：この生物像とは別に、市販品の由来を調べたのが、広域未確認生物研究所の中口研究員よ。


## experiment / analysis

**めたん**：人工ちくわの表示がある製品を分析し、原料魚に由来するタンパク質と、加熱で固まった組織構造を確認したの。

**ずんだもん**：ちゃんと調べているのだ。


## experiment / process

**めたん**：さらに、魚のすり身に塩を加えて練り、棒に巻いて加熱。弾力のある筒状の食品を、繰り返し再現できたわ。

**ずんだもん**：人工ちくわの製法としては、間違いなさそうなのだ。

**めたん**：天然物を採集せず、品質と供給を安定させられる利点もあるそうよ。

**ずんだもん**：便利なのは分かるけど、魚のまま食べる選択肢もあったはずなのだ。


## experiment / manufacturers

**めたん**：しかし、ここで中口研究員は、重大な疑問を抱いたの。なぜ複数のメーカーが、同じ製法を知っているのか。

**ずんだもん**：食品の製法だからなのだ。


## experiment / network

**めたん**：原料の調達から、加工、流通まで、全国に広がる巨大なネットワーク。背後には、国家規模の技術共有があると考えたわ。

**ずんだもん**：それを食品産業と呼ぶのだ。

**めたん**：ちくわという生物を模倣し、日常の食卓へ送り込む。その本当の目的は、まだ分かっていないの。

**ずんだもん**：おいしく食べてもらうためだと思うのだ。


## history / shimoju

**めたん**：一方、狭間文明研究所の霜重研究員は、魚肉を竹に巻いて焼く製法が、古くから記録されていることを確認したわ。

**ずんだもん**：最近始まった話でもないのだな。

**めたん**：製法の記述を時代ごとに比較すると、基本的な工程が継承されていることも分かったの。

**ずんだもん**：そこまでは、いい研究なのだ。


## history / oldnetwork
