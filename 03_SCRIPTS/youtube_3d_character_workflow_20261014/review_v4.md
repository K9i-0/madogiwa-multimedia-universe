# 完成版v4の改修・確認記録

## 反映したフィードバック

- 冒頭は現在の標準そば屋画像を並べる。最初は基準画像とBlender版、Tripo紹介からは3面比較。頭頂～足裏の大きさを揃え、全身が同時に読める構図にした。Blender版は残っている画像を使用し、3D版を復元したとは扱わない。
- 回転素材の実制作設定は720p、実画素数は832×1108と表示。今から3D入力素材を作る場合は、Wan 3.0で選べる最高設定の1080pを推奨する。投稿者の制作上のおすすめと公式のサービス仕様を区別する。
- 費用は1080p・8秒の通常価格試算へ変更。Wan 3.0は$0.20/秒×8秒=$1.60=256円、Tripoはそば屋制作の実例120 credits=$1.20=192円。1ドル160円で448円、会話では約450円。実際の720p制作記録は保持し、1080pの請求実績とは表現しない。
- ARの反応を「部屋にそば屋さん置けるんか。自宅まで窓際になりそうで嫌やなぁ……。」へ変更。Flutter Scene実例の反応は「スマホアプリにも、簡単に組み込めそうやね！」へ変更。
- 画面の文字量、公式ページとロゴの出典、Unity一般例とFlutter実録、初心者向けのやめ太郎の役割、たこさんの手2本＋足6本というv3の改善を継承。
