## 素材と作者

最初の4本は過去の投稿記録のSHA256と完全一致するローカルMP4を再利用する。過去の技術・目視監査を引き継ぎ、現在の動画hash・manifest hashと自動投稿の条件を検証した。新たな編集・音声生成・通し試聴は行っていない。

「缶ビールのマナー違反」は投稿前の原本がローカルに見つからなかったため、公開済みYouTubeの720×1280映像とAAC音声を取得し、再エンコードせずMP4へmuxした。`recovered/e2Ww-0RAps8.mp4` はYouTube圧縮版であり、投稿前原本と同一品質・同一hashではない。約51.62秒、24fps、1237映像フレーム、AV1＋AAC。全編デコードと映像・音声の存在、6秒間隔の代表フレームを確認。元ファイルの保存場所・制作者はユーザーへ質問済み。**作者は未確認のため、自動投稿の分類を既定のk9i側へ仮置き**した。回答を受けたらcreatorと予定表を修正する。これは実際の作者を断定する記録ではない。

動画はGit対象外でこのMacに保持する。削除前の公開情報とタイトル・概要欄・クレジットは `previous_uploads/` と `metadata/` に保存。再投稿で内容や概要欄を変えず、AI生成開示を明示する。

## 再投稿の状態管理

- `queue.json`: 5本ともready。旧IDはrepostOf、新しい投稿IDは投稿後にyoutubeIdへ記録する。
- `deletions/`: 個別の削除・非存在確認記録。旧URLは再生できない。
- `technical-audit.json` / `visual-audit.json`: 現在の入力に対応する監査。
- `publication-plan.json`: 既存列を含む68本の順番のスナップショット。
- `youtube_uploads/`: 再投稿後の新しい記録用。過去の投稿記録は元の場所に保持。

元のsobaya queueにある「勇者一行の帰還」はdeleted_for_repostとし、削除証跡を指す。旧記録による重複判定だけを解除し、新投稿記録による二重投稿防止を維持する。完了済みアップロードセッションは秘密情報の保管場所で退避し、旧YouTube IDが返らない状態にした。セッションURLや認証情報はこのディレクトリに保存していない。

YouTube公式は視聴者ごとの関連性、視聴実績、競合などを推薦要因として説明している。100再生未満だけから短期間の連続投稿が原因とは判定できず、再投稿による改善も未検証。今回の100再生はユーザー指定の抽出基準として用いた。
