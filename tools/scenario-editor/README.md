# 台本編集

`index.html` をダブルクリックしてブラウザーで開く。サーバー・インストール・外部通信は不要。今回の解説検証版16セリフを初期データとして同梱。

1. タイトルと全体の方針を編集する。
2. 上から順に話者・シーン・セリフを編集する。画面指示と修正メモは読み上げ対象と分離。
3. 必要なら追加・削除・上下移動する。
4. 「台本を全部コピー」を押し、チャットへ貼る。自動コピーできないブラウザーでは全文選択された欄から手動コピー。
5. 「編集データを保存」でJSONを書き出す。次回は「編集データを開く」。新作は「新しい台本」から開始。

自動保存は同じブラウザー・同じHTMLの保存領域を使用する。file URLのlocalStorage対応や保存先はブラウザーに依存するため、重要な台本はJSONも保存する。読み込みはこのエディターのversion 1形式のみ。台本はDOMのテキスト値として扱い、入力HTMLを実行しない。

コピーは台本全文と画面指示・修正メモを含むMarkdown形式。秒数・字幕改行は音声生成後に決め直すため編集対象に含めない。このツールからRemotionの正本は直接変更しない。チャットへ貼った台本を制作工程へ反映する。

検証：JavaScript構文、初期16セリフと修正メモの全文出力、編集したセリフの出力を確認。ブラウザー操作ツールはfile URLを拒否したため、実ブラウザーの操作検証は未実施。
