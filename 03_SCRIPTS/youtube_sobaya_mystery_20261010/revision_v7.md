# v7 修正記録

## 図解のタイミング

v6は門の表示開始を基準に固定時間で初回と追試を再生していたため、追試の説明前に動作が終了していた。

v7は `prepare_voice.py` がVOICEVOXのモーラごとの発音長から図解の開始点を計算し、WAV実測尺に合わせて整数フレームへ変換する。正本は `remotion/src/edit-manifest.json` の `visualCues`。図解は発言の開始ではなく、対象語句の発音位置で動く。

- 門：初回は「通過すると」から「移動できた」まで。追試は後の発言「もう一度」から「向こう側へ出た」まで。追試前には下段を見せない。
- モニター：大型表示、定規での計測、大きく測れた結果、小型表示を説明順に出す。
- 同じ映像3回：再生1回目、2回目、3回目、結論を順に表示。
- 同語反復・年代推定・水の共通点・秘密施設の比較：根拠と結論の先出しを抑える。
- 映画の報告書：作品名、古い機械、感想を対応する発言で表示。映画参照は一度だけ。
- 円筒：質問中は未開封の円筒のみ。振る→音→応答という解釈→国際会議、の順に表示。

## 担当の固定

| 人物 | 一貫した担当 |
| --- | --- |
| 木村研究員 | 原人・類人猿説。体格、顔、体毛、UMAとの比較。 |
| 霜重研究員（しもじゅう） | 古代文明説。門、儀式、三年の待機、遺跡、アトランティス、映画の資料。 |
| 北原研究員 | 宇宙人説。エリア51との比較、接近行動、円筒の調査、接触成功の発表。 |
| 林研究員 | 映像解析。再生、拡大、不明という結論、今後の解析の総括。 |
| 江本記者 | 冒頭の映像報道と、終盤の正体判明の報道。説の考察に途中参加しない。 |
| 中口 | 人事担当。正体を伝える連絡元。言語研究は霜重に統合。 |

各説の開始時に担当と説を一緒に紹介。初回紹介以降、同じ説に別の研究者や記者の名前を挟まない。設定・画面注記・台詞を合わせて更新。
