# 全8名・アニメーション確認版 v2

依頼者FBと鼻先で物を持つ参考画像を反映し、ユーザーのOKを受けた採用版。

- ゆめみん：画像から作り直し。手・腕なし。元の短い鼻先に木槌の柄の端を直接接触させて持つ。鼻を伸ばしたり柄へ巻き付けたりしない。尻尾は1本。体の中心を軸に、本体と木槌が一体で12度振りかぶり、逆向き52度まで地面へ振り下ろす。小さく反動を付けて戻り、休止。強調線と文字は固定。
- おかやまん：正典写真を参照し、手が見えない胸上の構図・真顔寄りの控えめな笑顔で画像を作り直した。手や指・顔の個別動作なし。人物と強調線が約6％アップになり、戻って静止する。文字は固定。
- 全員の文字：`../concepts_8_members_v3/all-members.png` の文字領域を直接使用し、採用画像の字形と相対サイズを維持。
- 汗・強調線：採用画像から抽出した固定レイヤーとして復元。ゆめみんの強調線は作り直したイラストに含める。
- そば屋：採用済みの手の動きと13フレーム・3秒のタイミングを維持し、文字・配置を一覧と同じに整えた。既存の採用正本は変更していない。

## ファイル

- `all-members-preview.gif`：4列×2段、1280×640、3秒ループ。
- `all-members-still.png`：今回の静止画一覧。
- `<member>/preview.gif`：個別GIF。
- `<member>/sticker.png`：透過APNG、320×270、3秒・1回再生。
- `<member>/still.png`：文字・装飾付き静止画。
- `members-review.zip`：ローカルの配布用一式（重複アーカイブはGit対象外）。

## 再生成

```sh
node 27_LINE_STICKERS/animated_members_v2/build.mjs
node 27_LINE_STICKERS/animated_members_v2/verify.mjs
```

ゆめみん・おかやまんの新規絵はbuilt-in Imagegenで作成。プロンプトは `prompts/`、入力・生成素材は `inputs/`。その他の採用済み動作はv1の入力から再利用する。v1の中間出力がなければ自動的にv1を再ビルドする。
ImageMagickで位置合わせ・合成・ズーム・中心回転、FFmpegでAPNG出力を行う。ゆめみんの鼻と木槌の位置関係は1枚の絵を一体で回転させることで維持する。よーたんは二重の手を避けるため6段階の描画ポーズで動かす。
`build/` は再生成可能な中間出力でGit対象外。`validation.json` に寸法・フレーム数・時間・読み込み・ループ端点検証を記録。
