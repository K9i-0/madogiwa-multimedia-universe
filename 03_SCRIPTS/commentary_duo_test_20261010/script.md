# たこさん・やめ太郎 立ち絵の動作テスト

ユーザー依頼：基本差分を作り、2人が向かい合う解説動画で動きを判断する。前ターンの斜め向きv2を使用。絵柄は各正典シートの3Dトイ表現。ずんだもんの絵柄は生成参照に使用しない。

## 台本

1. たこさん：今日は、立ち絵を使った解説のテストです。
2. やめ太郎：ワイらも、ついに解説する側になったんやな。
3. たこさん：話すと口が動いて、表情も変わります。
4. やめ太郎：おお、ちゃんと動いとる。仕事してるみたいや。
5. たこさん：見た目が動いても、仕事が進むとは限りません。
6. やめ太郎：初回から、ワイに厳しすぎるやろ。

## 制作仕様

- 内蔵image_genで発話口2枚、たこさん閉じ目、やめ太郎O口を生成。送信文はimage_prompts.json。
- たこさんは左で左右反転、やめ太郎は右で元の左向き。口・目も同じ親要素で反転。
- 全身の生成揺れを避け、生成差分の目・口の領域だけCSSマスクで重ねる。素材PNGは変更しない。
- 口パクは正規化音声のフレームRMS連動、2フレーム単位。たこさんは閉じ目の表情と周期的な瞬き。やめ太郎は白レンズ固定、O口と小さな反動で驚く。
- Remotion 4.0.534（npm viewで確認）、1280x720、30fps、776フレーム、25.8667秒。BGMなし。
- 音声：Aratako/Irodori-TTS-v4.1-Small。Takosan_voice.wav seed43、Yametaro_voice.wav seed7。caption空、CFG5、uncut1、尺倍率たこさん1／やめ太郎0.70。正典WAVは変更しない。編集用コピーだけ-18 LUFSへ調整。
- 台詞・seed・尺倍率：dialogue.json。実測尺・SHA256・開始フレーム・口パク波形：remotion/src/edit-manifest.json。
- 再生成：リポジトリルートでgenerate_voice.py、次いでIrodori環境のPythonでremotion/prepare.py。編集：remotionでnpm ci、npm run typecheck、npm run render。
- 完成動画：final_remotion_duo_test.mp4。視聴ページ：preview.html。

## 検証

型検査、実フレーム確認、ffprobe仕様確認、全編デコード、Whisperによる台詞照合を実施する。ASRは自動照合のみで、実試聴による声質・演技の採用判断とは区別する。

### 実施結果

- TypeScript型検査合格。初稿の6場面を実画像で確認し、右キャラを小さくして両者の足元を揃えた後に再レンダー。最終配置のフレームも確認。
- 最終MP4はH.264／AAC、1280×720、30fps、776映像フレーム、48kHz。コンテナ25.877秒。終端までデコードエラーなし。
- Whisper照合は6発話すべて対応。やめ太郎の「ワイら」「動いとる」に表記／語形の認識揺れあり。実試聴での発音・声質と細かな同期は未確認。ユーザーの視聴判断用初稿。
- ローカル視聴ページのHTTP200を確認しChromeで開いた。公開・Studio登録は実施していない。
