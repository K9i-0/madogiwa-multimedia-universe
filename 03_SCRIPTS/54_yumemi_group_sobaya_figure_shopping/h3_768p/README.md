## 再現

1. `python3 h3_768p/prepare.py <new-local-job-directory>`（EP内から実行可）
2. `.claude/skills/minimax-h3-video/scripts/colab_h3.py run`で既存CLI経路を利用。
3. 回収済みch01_768p.mp4、ch02_768p.mp4をremotion/public/h3/へhardlink。
4. remotionディレクトリで `npm run typecheck`、`node render-h3.mjs stills`、`node render-h3.mjs full`。
5. 元PCMを直接AAC muxするためRemotion出力の2048サンプル遅延を継承しない。映像はmux時stream copy。

既存Wan版、音声、台本は上書きしない。H3とWanは構成・生成方式も違うため、解像度だけを変えた厳密なA/B試験とはしない。
