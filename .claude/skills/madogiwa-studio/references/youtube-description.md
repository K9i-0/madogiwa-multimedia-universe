# 全動画のYouTube概要欄

2026-10-31ユーザー指定。物語・解説・音楽・Shorts共通。概要欄は簡潔にし、[登録・公開の共通手順](publication-workflow.md)と一緒に適用する。

## 標準内容

- あらすじを1〜2文。制作工程やタイトルの長い言い直しは不要。
- 実際に使ったVOICEVOXの話者名、フリー音源の曲名・作者・出典・ライセンス等、必要なクレジットを短く記載する。未使用の素材のクレジットを足さない。「フリー」だけで帰属不要と判断しない。
- **その作品の公式サイト制作ページURLを必ず載せる。** トップページURLだけで代用しない。動画生成AI作品は制作ノート公開まで行う。生成AI以外も実在する公式作品ページへリンクする。
- 関連ハッシュタグを末尾へ少数載せる（例：`#窓際族物語`＋登場人物・内容、Shortsなら`#Shorts`）。YouTubeメタデータの`snippet.tags`にも関連語を設定する。無関係な人気タグを追加しない。
- Shortsには現行本編リンクも載せる。必要な素材帰属・技術解説のAI向け資料等の重要リンクは省かない。公式トップページや工程説明を重複して増やさない。

```text
＜短いあらすじ＞

＜実使用素材の必要クレジット。未使用ならこの欄を省く＞

制作ノート
https://madogiwa.work/episodes/<作品slug>

＜Shortsのみ：本編URL＞

#窓際族物語 #＜関連タグ＞
```

## 制作ページへまとめる内容

細かな制作手順、プロンプト例、料金計算、設定の説明、制作ログ、参考リンク一覧、詳しい補足は、公開する制作ページ・解説資料へまとめる。非公開素材を移さず、公開済み／公開対象として確認した資料だけを使う。概要欄に同じ内容を再掲しない。

手動のタイムスタンプ・チャプター一覧は標準では載せない。公式UIに任せる方針であり、自動チャプターの生成を保証したり、動画・アカウント設定を変更したりする指示ではない。文字数の固定上限は設けず、必要なクレジット量に合わせる。

## 更新と検証

- 全作品で本編・Shortsの双方について、公開ページと概要欄内URLの一致、必要クレジット、ハッシュタグ・`snippet.tags`を再取得して確認する。初回アップロード時に制作ページが未公開なら、公開確認後に同じ作業内で追記する。
- 技術解説は[AI向け資料](explainer-ai-guide.md)の動画資料・実行指示書の両方の公開と本文取得を確認してから、その制作ページのリンクを概要欄へ反映する。存在しないリンクを掲載しない。
- `youtube_description.txt` と `youtube_metadata.json` のdescriptionを揃える。今回編集していない公開状態・予約日時・タイトル等をローカルmetadataからまとめて送らない。
- 既存動画を更新するときは現行snippetを取得し、説明文だけを変更する。他の編集可能なsnippet項目を保持し、不要なstatus更新をしない。更新後は再取得して本文と他項目の保持を確認する。直後に旧値が返る場合は短い間隔で再取得し、無制限に再送しない。
- この方針の追加だけを理由に、無関係な過去動画の概要欄を一括変更しない。新規制作・投稿準備と、依頼された既存動画の改修へ適用する。

採用例は `03_SCRIPTS/youtube_3d_character_workflow_20261014/`、`youtube_ai_video_workflow_20261013/`、`youtube_line_stickers_20261015/` の現行 `youtube_description.txt`（各パスはリポジトリルート基準）。固有のBGM・リンク・商標文を別作品へそのまま転用しない。
