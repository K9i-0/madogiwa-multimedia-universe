# めたんのミステリー研究所 第2回：ちくわ人工物説

採用方針v6：ずんだもんは「ちくわは生き物」という世界の常識を最後まで守る。めたんと研究員が、観察・実験から人工ちくわ流通説を唱え、さらに陰謀論へ飛躍する。人工ちくわと政府・企業による隠蔽は作品内で実在。林・江本は登場させない。分類・生態・研究内容・T社は作品内の架空設定。


## intro / opening

**めたん**：海に生息し、山にも分布する、身近な生き物。ちくわ。

**ずんだもん**：秋は山のちくわがおいしいのだ。

**めたん**：しかし今、そのちくわに、作りものが紛れ込んでいるという疑惑が持ち上がっているわ。


## intro / claim

**めたん**：魚の肉をすり潰し、棒に巻いて焼く。それを、本物のちくわとして売っているというの。

**ずんだもん**：なんでそんなことするのだ。ちくわを採ればいいのだ。


## intro / title

**めたん**：私たちが食べているのは、生き物なのか。それとも、作りものなのか。今日は、この謎に迫るわ。

**めたん**：めたんのミステリー研究所へ、ようこそ。このチャンネルでは、身近な常識に潜む謎を、研究員たちの調査とともに追っていきます。今夜のテーマは、あなたが食べたちくわは、本当にちくわだったのか。


## biology / ranks

**めたん**：まず、一般的な分類を確認しましょう。ちくわは、管状動物門、真管綱、チクワ目に属する動物よ。


## biology / species

**めたん**：海産のウミチクワと、山産のヤマチクワは、共通祖先から分かれた別の種とされているわ。

**ずんだもん**：このあたりは義務教育でみんな習うのだ。ちくわが生き物なんて、いまさら説明することでもないのだ。


## biology / anatomy

**めたん**：中央の穴は、水や空気を通す通水腔。体内の細い水路とつながり、物質の交換を助けているの。

**めたん**：明確な頭部を持たず、神経が身体全体に広がる。初期の動物に見られる、単純な体制を残しているわ。

**ずんだもん**：昔の特徴は残っていても、ちくわなりに進化は続けているのだ。


## biology / escape

**めたん**：過去の記録映像でも、野生個体の移動が確認できるわ。

**ずんだもん**：生き物なのは、見れば分かるのだ。


## biology / comparison

**めたん**：こちらは食用種と有毒種。外見だけでの判別は困難とされているわ。

**ずんだもん**：全く見分けがつかないのだ。


## biology / attraction

**めたん**：有毒種にはビール臭があり、代表的な天敵、ソバヤを引き寄せてしまうの。

**ずんだもん**：天敵の好物みたいな匂いを出すのは、損なのだ。


## experiment / nakaguchi

**めたん**：ところが広域未確認生物研究所の中口研究員は、市販のちくわに、生き物ではないものが混ざっていると主張しているわ。


## experiment / analysis

**めたん**：購入したちくわを分析し、魚肉に似たタンパク質と、加熱で固まった組織を確認。原料は魚ではないかと考えたの。

**ずんだもん**：ちくわを調べたのだから、ちくわの成分なのだ。焼いたちくわは、当然、加熱されているのだ。


## experiment / process

**めたん**：そこで魚のすり身に塩を加えて練り、棒に巻いて加熱。ちくわに似た、弾力のある筒状の食品を再現したわ。

**ずんだもん**：魚を潰して、ちくわの替え玉を作ったのだ？ その手間で、本物を採ってくるのだ。

**めたん**：研究員が恐れているのは、この替え玉が、本物に混ぜて売られている可能性よ。私たちは、気づかないまま食べているのかもしれない。

**ずんだもん**：そんなものを混ぜられたら困るのだ。でも、研究員が作った偽物を、店で売っている証拠にはできないのだ。


## experiment / manufacturers

**めたん**：中口研究員は、購入品の一部に、不自然なほど均一な穴と、継ぎ目のような跡があると指摘したわ。生き物の身体ではなく、型で作った痕跡ではないかと。

**ずんだもん**：形のいいちくわを選んで袋に詰めたら、偽造の容疑をかけられたのだ。


## experiment / network

**めたん**：もし偽物が本物に混ざり、同じ売り場に並んでいたら、食卓に届くころには誰も疑わない。研究員は、このすり替えを支える国家規模の組織があると考えたわ。

**ずんだもん**：穴がきれいなだけで、国家ぐるみの食品偽装にするな。

**めたん**：ちくわという生物を模倣し、日常の食卓へ送り込む。その本当の目的は、まだ分かっていないの。

**ずんだもん**：目的の前に、流通しているという証拠が足りないのだ。


## history / shimoju

**めたん**：一方、狭間文明研究所の霜重研究員は、魚肉を竹に巻いて焼く方法が、古い文献に記されていることを確認したわ。

**ずんだもん**：昔にも、ちくわの偽物を作る暇な人がいたのだな。

**めたん**：時代の異なる資料にも、同じような工程がある。霜重研究員は、人工ちくわの製造が長く続いてきた証拠と考えたの。

**ずんだもん**：こんな古文書の画像、いまならAIでいくらでも捏造できるのだ。現物は確認したのだ？


## history / oldnetwork

**めたん**：霜重研究員は、画像に残る製法が、何度も政権交代を生き延びている点に注目。政府より長く存在する組織を疑ったわ。

**ずんだもん**：現物の確認はどうしたのだ。レシピが長持ちしただけで、秘密結社を作るな。


## infiltration / factory

**めたん**：人工ちくわの闇に迫るため、研究員は、日本の大手加工食品メーカー、T社への潜入調査を決行したの。

**ずんだもん**：ちくわを洗って袋に詰める工場に、何の闇があるのだ。


## infiltration / arrest

**めたん**：しかし、その直後。霜重研究員は、現地で身柄を拘束されたわ。

**ずんだもん**：何をしたのだ？

**めたん**：表向きの理由は、不法侵入とされているわ。

**ずんだもん**：表向き？


## infiltration / conspiracy

**めたん**：真相に近づいた研究者の逮捕。私は、背後にある闇の組織が、彼の調査を妨害したと考えているわ。

**ずんだもん**：まず、取材の約束はしていたのだ？


## infiltration / noappointment

**ずんだもん**：アポなしなのだ。

**ずんだもん**：通報したからなのだ。

**めたん**：一食品メーカーの問題に、公的機関が介入した。研究員は、この一件で企業と国家を結ぶ線が見えたと話しているわ。

**ずんだもん**：通報の電話線なのだ。


## infiltration / report

**ずんだもん**：自分が暴れたところも書くのだ。


## infiltration / additional_charge

**めたん**：なお、霜重研究員は、不法侵入に加えて、猥褻物陳列罪の容疑でも逮捕されているわ。

**ずんだもん**：酒癖が悪すぎるのだ。


## supply / kitahara

**めたん**：霜重研究員が身柄を拘束される一方、未知環境生理研究所の北原研究員は、別の疑問を追っていたわ。

**ずんだもん**：今度は、お酒を飲まずに調べてほしいのだ。


## supply / seasons

**めたん**：山産のちくわは、本来、秋に採集量が増える生き物よ。ところが今は、一年中、同じ大きさのものが店に並んでいる。

**ずんだもん**：養殖技術が進歩したからなのだ。学校でも習ったのだ。


## supply / official

**めたん**：政府と業界団体も、通年供給は養殖技術の発展によって実現したと説明しているわ。

**ずんだもん**：なら、謎は解けたのだ。

**めたん**：北原研究員も、最初はそう考えたの。そこで、生産地と養殖施設の公開資料を照合したわ。


## supply / capacity

**めたん**：ところが、確認できた飼育面積と成長期間では、公表された出荷量を説明できなかった。

**ずんだもん**：公開されていない養殖場もあるのでは？

**めたん**：その可能性はあるわ。だから研究員は、企業へ施設の所在地と飼育方法を問い合わせたの。

**ずんだもん**：ちゃんと問い合わせたのだ。霜重より一段階進んでいるのだ。


## supply / secret

**めたん**：回答は、独自の養殖技術に関わるため非公開。政府側も、個別企業の生産技術については回答を控えるとしたわ。

**ずんだもん**：企業秘密なら、全部は見せられないのだ。

**めたん**：誰も施設を見せない。でも、誰もが養殖であることだけは保証している。

**ずんだもん**：見せないことだけで、存在しないとは言えないのだ。


## supply / balance

**めたん**：そこで北原研究員は、工場に入るものと、出てくるものに注目したわ。運び込まれるのは、大量の魚肉。

**ずんだもん**：ちくわの餌なのだ。

**めたん**：出荷されるちくわの量は、投入された魚肉の重量に極めて近かったの。

**ずんだもん**：餌の無駄が少ないのだな。

**めたん**：普通は、呼吸や運動に使う分、排泄する分がある。食べた餌が、そのまま身体になるわけではないでしょう。

**ずんだもん**：水分の量とか、集計の期間も確認するのだ。

**めたん**：ええ。この比較だけでは断定できない。ただ、餌と呼ばれたものが、原料だったと考えると、別の説明がつくわ。


## supply / growth

**めたん**：そして、公開された工場の紹介映像。魚肉を練り、棒に巻き、加熱した直後に、出荷できる大きさのちくわが現れる。

**ずんだもん**：養殖技術を分かりやすく説明するための模型かもしれないのだ。

**めたん**：産卵も、孵化も、成長を待つ時間も、そこには映っていない。

**ずんだもん**：工場紹介で一生分を撮影する必要はないのだ。

**めたん**：北原研究員は結論づけたわ。これは、異常に速い養殖ではない。生き物を育てていないのよ。


## conspiracy2 / substitution

**めたん**：魚肉で形を作り、天然物や養殖物に紛れ込ませる。そして、消費者には、ちくわとして渡す。

**ずんだもん**：それが本当なら、食品偽装なのだ。でも、まだ研究員の推測なのだ。

**めたん**：問題は、なぜ政府まで、養殖という説明を繰り返しているのか。

**ずんだもん**：企業から、そう報告されているのでは？


## conspiracy2 / leap

**めたん**：政府も企業も、同じ説明。北原研究員は、背後にある情報統制機構の存在を確信したわ。

**ずんだもん**：回答が似ているだけで、闇の政府を設立するな。

**めたん**：私は、もっと深刻だと思っているの。これは、私たちが何を生き物と認識するかを、管理する計画よ。

**ずんだもん**：ちくわの仕入れから、人類の認識まで話を広げるな。


## conspiracy2 / education

**めたん**：学校で、養殖技術の発展を習う。店では、養殖ちくわを買う。疑問を持たずに、次の世代へ同じ説明を伝える。

**ずんだもん**：普通の食育なのだ。

**めたん**：その説明の中に、魚肉を棒に巻く工程は、一度も出てこない。

**ずんだもん**：生き物を育てる授業だからなのだ。

**めたん**：この仕組みが完成すれば、ちくわ自身が一度も生きていなくても、社会の側が生き物として扱ってくれるのよ。

**ずんだもん**：言い方だけは、ものすごく怖いのだ。


## conspiracy2 / network

**めたん**：研究員は、工場、物流、学校、そして家庭の食卓を、一枚の図にまとめたわ。

**ずんだもん**：線を引けば、何でもつながるのだ。

**めたん**：でも、中心に置いたはずの養殖場だけが、確認できない。

**ずんだもん**：だから、まずは見学できる養殖場を探すのだ。世界の支配者を探す前に。


## ending / findings

**めたん**：魚肉から作られる、もう一つのちくわ。それが本物に混ざり、養殖技術の発展という説明で、食卓に届いている。研究チームは、そう結論づけたわ。

**ずんだもん**：僕は、本物のちくわを買っているつもりなのだ。違うものなら、違うと書いてほしいのだ。

**めたん**：昨日あなたが食べた一本も、海にも山にも、一度もいたことがないのかもしれない。

**ずんだもん**：不安にさせて終わるな。証拠をそろえて、ちゃんと告発するのだ。
